## 🏛️ 冯·诺依曼机与现代计算机架构

### ❓ 冯·诺依曼机有几个组成部分，以什么为中心？现代计算机又以什么为中心？这样设计的原因是什么？

* **冯·诺依曼机五大基本部件**：
  1. **输入设备 (Input Device)**
  2. **输出设备 (Output Device)**
  3. **运算器 (ALU)**
  4. **存储器 (Memory)**
  5. **控制器 (CU)**
* **结构中心演变**：
  * 经典冯·诺依曼机：**以运算器为中心**；
  * 现代微型计算机：**以存储器为中心**。
* **设计根本原因**：
  * 解放 CPU，方便进行 DMA 等 **I/O 操作时绕开 CPU**，使 I/O 操作直接与主存交换数据，实现 CPU 与外部设备的并行工作。
::: tip 💡 408 核心避坑
**硬盘属于 I/O 设备（外存）**，计算机内部存储器仅指内存（主存与 Cache）！
:::

---

### ❓ MAR 和 MDR 是在 CPU 中还是在存储器中？地址译码器在哪个部件中？

* **MAR (存储器地址寄存器)** 与 **MDR (存储器数据寄存器)**：
  * 虽然逻辑上归属于主存系统，但在现代计算机的物理硬件实现中，**MAR 和 MDR 集成在 CPU 芯片内部**，以缩短电气走线和访问延迟。
* **地址译码器**：
  * **位于主存芯片（内存条）内部**，负责将 MAR 发来的地址总线信号译码并选中特定的存储单元（注：硬盘驱动器内也有相应的磁道/扇区译码电路）。

## 🔗 程序链接三大方式辨析

### ❓ 静态链接、装入时动态链接与运行时动态链接的区别？

```
  [目标模块 A] ──┐
                 ├──> [静态链接] ─────────> 形成完整单一可执行文件 (从 00000 开始)
  [目标模块 B] ──┘

  [装入时动态链接] ──> 在装入内存时边装入边链接，A 与 B 可分散装入内存不连续的位置
  [运行时动态链接] ──> 程序执行过程中用到该模块时，才将其动态调入内存并链接绑定
```

1. **静态链接**：在程序运行前，将目标模块以及它们所需的库函数链接成一个完整的逻辑地址空间连续的可执行程序（地址从 0 开始）；
2. **装入时动态链接**：目标模块在装入内存时边装入边链接，允许各模块装载到内存中不连续的物理页面中；
3. **运行时动态链接**：某些目标模块在程序运行中真正被调用时才装入并链接（如 Windows DLL、Linux `.so`），大幅节约主存空间，便于模块热更新。

## 📊 计算机性能指标与量级换算

### ❓ MIPS 与 MFLOPS 的区别？

* **MIPS (Million Instructions Per Second)**：每秒钟执行**百万条指令数**。
  $$\text{MIPS} = \frac{\text{指令条数}}{\text{执行时间} \times 10^6} = \frac{f}{\text{CPI} \times 10^6}$$
* **MFLOPS (Million Floating-point Operations Per Second)**：每秒钟执行**百万次浮点运算**。
  * 扩展层级：GFLOPS ($10^9$)、TFLOPS ($10^{12}$)、PFLOPS ($10^{15}$)。

::: tip 💡 408 必考前缀进率陷阱
* **描述速率、频率与时钟时（以 10 的幂为单位）**：
  $$K = 10^3, \quad M = 10^6, \quad G = 10^9, \quad T = 10^{12}, \quad P = 10^{15}, \quad E = 10^{18}, \quad Z = 10^{21}$$
  （后一个单位恒比前一个增加 $10^3$）。
* **描述存储容量、地址空间时（以 2 的幂为单位）**：
  $$1\text{ KB} = 2^{10}\text{ B} = 1024\text{ B}, \quad 1\text{ MB} = 2^{20}\text{ B}, \quad 1\text{ GB} = 2^{30}\text{ B}, \quad 1\text{ TB} = 2^{40}\text{ B}$$
:::

## 🧩 CPU 构件划分与透明性辨析

### ❓ 运算器与控制器具体包含哪些寄存器？

$$\text{CPU} = \text{运算器} + \text{控制器}$$

* **控制器包含**：
  * **PC (程序计数器)**：存放下一条将要执行的指令在主存中的地址；
  * **IR (指令寄存器)**：存放当前正在执行的指令机器码；
  * **CU (控制单元)**：译码指令并发出微操作控制时序信号；
  * **MAR / MDR**：访存地址与数据暂存缓冲。
* **运算器包含**：
  * **ALU (算术逻辑单元)**：核心算术与逻辑运算运算器；
  * **ACC (累加器)**：存放操作数或运算结果；
  * **MQ (乘商寄存器)**：在乘法中存放乘数/积的低位，在除法中存放商；
  * **X (通用操作数寄存器)**：存放另一个源操作数；
  * **PSW (程序状态字寄存器)**：记录状态标志位（ZF, OF, SF, CF）和中断使能控制位。

---

### ❓ 哪些寄存器对汇编程序员是“透明”（不可见）的？

* **对汇编程序员透明（不可通过指令直接读写、寻址）**：
  * **IR (指令寄存器)**：CPU 内部自动加载当前指令，程序员无法直接访问；
  * **MAR (存储器地址寄存器)**：硬件自动打入访存地址；
  * **MDR (存储器数据寄存器)**：硬件自动暂存访存数据；
  * **内部暂存寄存器 (Y/Z 暂存器)**。
* **对汇编程序员可见（可通过指令直接操作、寻址）**：
  * **PC (程序计数器)**：可通过转移指令 `JMP` 间接改变；
  * **通用寄存器组**（如 ACC, R0~R31, AX, BX 等）；
  * **PSW (程序状态字寄存器)**：状态标志位可通过分支指令测试，控制位可通过特权指令修改（注：有些教辅中指出 PSW 的某些内部测试位对程序员透明）。
