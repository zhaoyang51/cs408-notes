## 1. 原码、反码、补码、移码表示范围（以 $n$ 位整数为例）

| 码制 | 定点整数表示范围 | 定点小数表示范围 | 零的表示 |
|:---|:---:|:---:|:---:|
| **原码** | $-(2^{n-1}-1) \sim +(2^{n-1}-1)$ | $-(1-2^{-(n-1)}) \sim +(1-2^{-(n-1)})$ | 存在 $+0$ 与 $-0$ 两种表示 |
| **反码** | $-(2^{n-1}-1) \sim +(2^{n-1}-1)$ | $-(1-2^{-(n-1)}) \sim +(1-2^{-(n-1)})$ | 存在 $+0$ 与 $-0$ 两种表示 |
| **补码** | **$-2^{n-1} \sim +(2^{n-1}-1)$** | **$-1 \sim +(1-2^{-(n-1)})$** | **零的表示唯一**（$[+0]_{\text{补}} = [-0]_{\text{补}} = 0$） |
| **移码** | $-2^{n-1} \sim +(2^{n-1}-1)$ | （仅用于表示浮点数阶码整数） | 零的表示唯一（符号位与补码正好相反） |

::: tip 💡 补码定点整数特异值
8 位补码：$-128 = 1000\,0000_2$；$+127 = 0111\,1111_2$；$-1 = 1111\,1111_2$。
:::

## 2. 定点数加减法溢出判断（3 大判决法）

1. **单符号位比较法**：两个正数相加结果为负数，或两个负数相加结果为正数，则必发生溢出；
2. **最高有效位与符号位进位法**：设符号位进位为 $C_s$，最高数值位进位为 $C_1$，溢出条件为 $V = C_s \oplus C_1 = 1$；
3. **双符号位（变形补码 / 模 4 补码）**：运算结果符号位为 `00` (正无溢出)、`11` (负无溢出)、`01` (正溢出)、`10` (负溢出)。

## 3. IEEE 754 浮点数标准全拆解

::: info 💡 IEEE 754 单精度 float (32 位) 结构
```
 1 bit        8 bit                     23 bit
+-------+--------------------+------------------------------------+
| S(符) |    E (阶码移码)    |            M (尾数小数部分)        |
+-------+--------------------+------------------------------------+
```
- **真值公式**：$X = (-1)^S \times (1.M) \times 2^{E - 127}$
  - $S$: 0 为正，1 为负；
  - $E$: 阶码用移码表示，偏置常数 $\text{Bias} = 127$（取值范围 $1 \sim 254$，对应真实指数 $-126 \sim +127$）；
  - $M$: 尾数规格化隐藏最高位 1，实际有效精度为 $1 + 23 = 24$ 位。
- **特殊值判定**：
  - $E = 255, M = 0 \implies \pm \infty$（无穷大）；
  - $E = 255, M \ne 0 \implies \text{NaN}$（非数值，如 $0/0$）；
  - $E = 0, M = 0 \implies \pm 0$；
  - $E = 0, M \ne 0 \implies$ 非规格化数（真值 $= (-1)^S \times 0.M \times 2^{-126}$）。
:::

## 4. 大端序 (Big-Endian) vs 小端序 (Little-Endian)
- **大端序 (Big-Endian)**：**高位字节存低地址**，低位字节存高地址（与人类日常阅读顺序一致）；
- **小端序 (Little-Endian)**：**低位字节存低地址**，高位字节存高地址（x86 架构标准）。
