## 1. 8 大常见指令寻址方式全景速查

| 寻址方式 | 有效地址 (EA) 计算公式 | 访存次数 (取指后) | 核心特点与典型应用场景 |
|:---|:---|:---:|:---|
| **隐含寻址** | 操作数隐含在专用寄存器 (如 ACC) | 0 | 指令字中无地址码，缩短指令长度 |
| **立即寻址** | $\text{操作数} = \text{形式地址 } A$ | 0 | 形式地址即为常数操作数本身，速度最快 |
| **直接寻址** | $\text{EA} = A$ | 1 | 形式地址即为操作数在内存的物理地址 |
| **间接寻址** | $\text{EA} = (A)$ (一次间址) | $\ge 2$ | 扩大寻址范围，支持指针与动态地址 |
| **寄存器寻址** | $\text{操作数} = R_i$ | 0 | 操作数直接在 CPU 寄存器中，执行极快 |
| **寄存器间接** | $\text{EA} = (R_i)$ | 1 | 寄存器存放内存地址，比间接寻址少 1 次访存 |
| **相对寻址** | $\text{EA} = (\text{PC}) + A$ | 1 | **基于当前 PC 偏移**，用于程序相对跳转与循环 |
| **基址寻址** | $\text{EA} = (\text{BR}) + A$ | 1 | **基址寄存器由 OS 管理**，形式地址由用户提供，用于多道程序定位 |
| **变址寻址** | $\text{EA} = (\text{IX}) + A$ | 1 | **变址寄存器由用户修改**，形式地址基准固定，用于数组/向量遍历 |

## 2. CISC vs RISC 指令系统对比

| 对比维度 | CISC (复杂指令系统) | RISC (精简指令系统) |
|:---|:---|:---|
| **指令数量** | 庞大（数百条），变长指令字长 | 精简（百余条），**定长指令字长**（常用 32 位） |
| **寻址方式** | 丰富多样，支持多种复杂组合 | 简单，通常不超过 3~4 种 |
| **访存指令** | 绝大多数指令均可直接访存 | **严格限制：仅 Load / Store 指令访存** |
| **通用寄存器** | 数量较少 | 数量极多（32 个以上） |
| **控制器实现** | 绝大多数采用**微程序控制器** | 绝大多数采用**硬布线逻辑控制器**（硬连线） |
| **指令流水线** | 难以实现高效流水线 | **高度优化，单周期指令执行**，流水线效率极高 |
