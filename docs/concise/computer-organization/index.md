## 🎯 408 计组三大计算命脉

1. **Cache 与主存映射地址切分**：Tag（主存标记） + Index/Set（Cache 行号/组号） + Offset（块内字节地址）；
2. **IEEE 754 浮点数编解码**：$(-1)^s \times 1.M \times 2^{E - 127}$ 符号、阶码移码、尾数规格化；
3. **软硬件全链路中断处理**：关中断 ➔ 保存断点 ➔ 引出中断向量 ➔ 保存现场 ➔ 开中断 ➔ 执行服务 ➔ 关中断 ➔ 恢复现场 ➔ 开中断 ➔ 中断返回。
