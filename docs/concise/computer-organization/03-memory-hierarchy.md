## 1. 主存与 Cache 3 大映射方式地址切分与计算

| 映射方式 | 主存地址字段切分 | 映射规则与特点 | 硬件开销与冲突率 |
|:---|:---|:---|:---|
| **直接映射 (Direct)** | `[ Tag 主存标记 | Index Cache行号 | Offset 块内地址 ]` | 主存块只能固定映射到 $j = i \pmod{M}$ 某一行 | 比较器硬件简单，冲突率最高 |
| **全相联映射 (Fully)** | `[ Tag 主存标记 | Offset 块内地址 ]` | 主存块可放入 Cache 中的任意一行 | 冲突率最低，但需与所有行 Tag 同时比较，开销极大 |
| **组相联映射 (Set-Assoc)** | `[ Tag 主存标记 | Set 组号 | Offset 块内地址 ]` | 主存块映射到固定组 $q = i \pmod{Q}$，组内任一行均可放 | 408 核心重点！兼顾速度与命中率 |

::: info 💡 $k$ 路组相联主存地址位数切分计算黄金模板
设主存容量 $2^m$ 字节（主存地址 $m$ 位），Cache 容量 $2^c$ 字节，块大小 $2^b$ 字节，采用 $k = 2^r$ 路组相联映射：
1. **块内偏移位数 (Offset)**：$b$ 位；
2. **Cache 总行数**：$M = 2^{c - b}$ 行；
3. **Cache 总组数**：$Q = \frac{M}{k} = 2^{c - b - r}$ 组 ➔ **组号字段位数 (Set)**：$s = c - b - r$ 位；
4. **主存标记位数 (Tag)**：$t = m - s - b$ 位。
:::

## 2. 虚拟存储器与两级页表地址转换

- **虚拟地址结构**：`[ 一级页号 (10b) | 二级页号 (10b) | 页内偏移 (12b, 4KB页) ]`；
- **全链路访存与命中判定流程**：
  1. 查 TLB 快表 ➔ 若命中，直接得到物理页框号；
  2. 若 TLB 未命中 ➔ 查内存页表 ➔ 若命中，将页表项装入 TLB；
  3. 若页表有效位为 0 ➔ 触发**缺页中断 (Page Fault)**，从磁盘调入页面；
  4. 得到物理地址后 ➔ 访问 Cache ➔ 若命中直接返回数据，未命中则访问主存。
