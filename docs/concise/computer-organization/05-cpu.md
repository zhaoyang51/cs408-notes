## 1. 硬布线控制器 vs 微程序控制器核心对比

| 对比维度 | 硬布线逻辑控制器 (组合逻辑) | 微程序控制器 (存储逻辑) |
|:---|:---|:---|
| **核心实现原理** | 纯硬件门电路与触发器组合逻辑 | 采用软件设计思想，将微指令存入**控制存储器 (CS)** |
| **执行速度** | **极快**（门电路硬件延迟极小，主频高） | 较慢（每条微指令均需从控存 CS 读出） |
| **指令扩充与修改** | **极难**（必须重新修改硬件布线打板） | **极易**（只需向控存中写入新的微程序即可） |
| **适用架构体系** | 主要应用于 **RISC** 高性能处理器 | 主要应用于 **CISC** 复杂指令处理器 |

## 2. 指令流水线 3 大冒险 (Hazards) 与解决方案

::: info 💡 流水线 3 大冒险全景
1. **结构冒险 (资源冲突 - Structural Hazard)**：多条指令在同一时钟周期竞争同一硬件资源（如同时读写同一内存）。
   - *解决方案*：指令与数据 Cache 分离（哈佛结构）、流水线插入气泡 (Bubble)。
2. **数据冒险 (数据相关 - Data Hazard)**：下一条指令需要使用上一条指令的计算结果，但上一条尚未写回。
   - *类型*：写后读 (RAW - 真相关)、读后写 (WAR - 反相关)、写后写 (WAW - 输出相关)；
   - *解决方案*：**数据旁路技术 (Forwarding / 转发)**（直接从 ALU 输出引线至下一指令输入端）、软件编译重排、硬件插入气泡。
3. **控制冒险 (分支跳转 - Control Hazard)**：条件转移或异常跳转导致 PC 改变，流水线预取的后续指令作废。
   - *解决方案*：**分支预测技术 (静态/动态预测)**、延迟分支 (Branch Delay Slot)、早期生成目标地址。
:::

## 3. 指令流水线性能指标公式

- **吞吐率 (Throughput)**：$TP = \frac{n}{(k + n - 1)\Delta t}$（$k$ 为流水线级数，$n$ 为任务数）；
- **加速比 (Speedup)**：$S = \frac{k \cdot n}{k + n - 1} \xrightarrow{n \to \infty} k$；
- **流水线效率 (Efficiency)**：$E = \frac{n}{k + n - 1}$。
