## 1. 顺序表 vs 链式表特性对比

| 操作维度 | 顺序表 (Array List) | 单链表 / 双链表 (Linked List) |
|:---|:---|:---|
| **存取方式** | **支持随机直接存取 $O(1)$**（通过下标 `data[i]`） | **仅支持顺序存取 $O(n)$**（需从头指针沿 `next` 遍历） |
| **插入/删除元素** | 平均需移动 $\frac{n}{2}$ 个元素，时间复杂度 $O(n)$ | 找到位置后修改指针即可，时间复杂度 $O(1)$ |
| **空间分配** | 静态分配易溢出，动态扩容需大块连续内存 | 动态分配节点，按需申请，充分利用零碎内存 |
| **存储密度** | **存储密度 $= 1$**（100% 存放数据本身） | **存储密度 $< 1$**（每个节点需额外指针域开销） |

## 2. 408 链表算法大题 4 大核心技巧

1. **头插法 (Head Insertion)**：新节点插入到头节点之后，生成**倒序链表**，常用于链表原地逆置（时间 $O(n)$，空间 $O(1)$）；
2. **尾插法 (Tail Insertion)**：维护尾指针 `rear`，新节点接入尾部，保持原顺序；
3. **快慢双指针法 (Fast-Slow Pointers)**：
   - 快指针每次走 2 步，慢指针每次走 1 步 ➔ 快指针到尾部时，慢指针恰好指向**链表中点**；
   - 寻找倒数第 $k$ 个节点：快指针先走 $k$ 步，随后快慢指针同步前行，快指针到尾时慢指针即为所求。
4. **虚拟头节点 (Dummy Head)**：统一链表首节点与普通节点的插入删除逻辑，避免特判 `head == NULL`。
