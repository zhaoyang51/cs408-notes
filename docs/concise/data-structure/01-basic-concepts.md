## ⏱️ 算法时间复杂度经典计算题型

### 题型 1：双重循环（外层循环控制内层次数，循环结束与循环体无关）

```c
int sum = 0;
for (int i = 1; i < n; i *= 2) {
    for (int j = 0; j < i; j++) {
        sum++;
    }
}
```

* **严密推导过程**：
  * 外层变量 $i$ 的取值序列为：$1, 2, 4, 8, \dots, 2^k$（其中 $2^k < n$）；

| **轮次** | 第 1 轮 | 第 2 轮 | 第 3 轮 | $\dots$ | 第 $k+1$ 轮 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **$i$ 的值** | $1$ ($2^0$) | $2$ ($2^1$) | $4$ ($2^2$) | $\dots$ | $2^k$ |
| **内层执行次数** | $1$ 次 | $2$ 次 | $4$ 次 | $\dots$ | $2^k$ 次 |

  * 总执行次数 $S = 1 + 2 + 4 + \dots + 2^k$（等比数列求和）：
    $$S = \frac{1 \cdot (1 - 2^{k+1})}{1 - 2} = 2^{k+1} - 1 < 2n$$
  * 因此，该程序段的时间复杂度为：
    $$\mathbf{O(n)}$$

### 题型 2：单层循环关联循环体（循环结束与循环体累加值相关）

```c
int func(int n) {
    int i = 0, sum = 0;
    while (sum < n) {
        sum += ++i;
    }
    return i;
}
```

* **严密推导过程**：
  * 设循环共执行了 $T$ 轮：

| **轮次 ($t$)** | 第 1 轮 ($t=1$) | 第 2 轮 ($t=2$) | 第 3 轮 ($t=3$) | $\dots$ | 第 $T$ 轮 ($t=T$) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **$i$ 的值** | $1$ | $2$ | $3$ | $\dots$ | $T$ |
| **$\text{sum}$ 累计值** | $1$ | $1 + 2$ | $1 + 2 + 3$ | $\dots$ | $\frac{T(1 + T)}{2}$ |
  * 循环终止条件为 $\text{sum} \ge n$，即：
    $$\frac{T(1 + T)}{2} \approx \frac{T^2}{2} = n \implies T = \sqrt{2n}$$
  * 因此，该程序的时间复杂度为：
    $$\mathbf{O(\sqrt{n})} \quad \text{或} \quad \mathbf{O(n^{1/2})}$$

::: tip 💡 做题技巧
对于包含 `while(sum < n)` 且 `sum += i` 的循环，**本质是求执行次数 $T$ 与上界 $n$ 的函数方程**！
:::

## 🧩 逻辑结构 vs 存储结构判定法则

### ❓ 如何快速判定一个概念是“逻辑结构”还是“存储结构”？

> 💡 **核心判决法则**：**看它是否使用了或依赖了计算机内存中具体的物理存储方式！**

* **逻辑结构（与计算机硬件和内存分配完全无关，面向问题本身建模）**：
  * **集合结构**：元素间除“同属一个集合”外无其他关系；
  * **线性结构**：元素之间存在一对一的前驱后继关系（如：**线性表、栈、队列、字符串、数组**）；
  * **树形结构**：元素之间存在一对多的层次关系（如：**二叉树、树、森林**）；
  * **图形结构 / 网状结构**：元素之间存在多对多的任意网状关系（如：**有向图、无向图**）。
* **存储结构 / 物理结构（面向计算机内存的实际落地实现）**：
  * **顺序存储**：逻辑相邻物理连续（如：**顺序表、循环队列、一维/二维数组**）；
  * **链式存储**：通过指针显式链接，物理离散（如：**单链表、双链表、二叉链表、十字链表**）；
  * **索引存储**：建立附加索引表实现检索（如：**索引表、B 树、B+ 树**）；
  * **散列存储 / Hash 存储**：通过哈希函数计算物理存储地址（如：**散列表、哈希表**）。

::: warning ⚠️ 命题高频易错题
* “栈”和“队列”属于**逻辑结构**；
* “顺序栈”、“链栈”、“循环队列”属于**存储结构**！
:::
