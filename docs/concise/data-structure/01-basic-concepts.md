## 1. 数据结构 3 要素全景

1. **逻辑结构**：面向问题本质，与计算机存储无关。分为：
   - **线性结构**：线性表、栈、队列、数组、串（一对一关系）；
   - **非线性结构**：树（一对多）、图（多对多）、集合（无序无关系）。
2. **存储结构 (物理结构)**：在计算机内存中的表示方式。包括：
   - **顺序存储**：逻辑相邻物理亦相邻，支持随机存取，插入删除需移动元素；
   - **链式存储**：节点包含数据域和指针域，物理不连续，扩充灵活，不支持随机存取；
   - **索引存储**：建立附加索引表，检索快，占用额外索引空间；
   - **散列存储 (Hash)**：通过散列函数直接计算物理存储地址。
3. **数据的运算**：定义在逻辑结构上，实现于存储结构中。

## 2. 渐进时间复杂度阶数排序（由优到劣）

$$O(1) < O(\log_2 n) < O(n) < O(n \log_2 n) < O(n^2) < O(n^3) < O(2^n) < O(n!) < O(n^n)$$

::: tip 💡 常见算法时空复杂度速查
- 二分查找：$O(\log n)$；
- 树的深度遍历 / 图遍历：$O(V + E)$；
- 归并排序 / 堆排序 / 快速排序平均：$O(n \log n)$；
- 冒泡 / 插入 / 选择排序：$O(n^2)$。
:::
