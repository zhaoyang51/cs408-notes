## 1. 栈的性质与卡特兰数

- **后进先出 (LIFO)**：仅允许在栈顶一端进行插入 (Push) 和删除 (Pop) 操作；
- **$n$ 个不同元素进栈，合法出栈序列总数（卡特兰数 Catalan）**：
  $$f(n) = \frac{1}{n + 1} C_{2n}^n = \frac{(2n)!}{(n + 1)! \, n!}$$
  - $n=1 \to 1$；$n=2 \to 2$；$n=3 \to 5$；$n=4 \to 14$；$n=5 \to 42$。

## 2. 循环队列 3 种判空判满方案（容量为 $M$）

| 区分方案 | 队空判定条件 | 队满判定条件 | 队列实际元素个数计算 |
|:---|:---|:---|:---|
| **1. 牺牲一个存储单元** | `front == rear` | **`(rear + 1) % M == front`** | `(rear - front + M) % M` |
| **2. 增设 size 计数器** | `size == 0` | `size == M` | `size` |
| **3. 增设 tag 状态标志** | `front == rear && tag == 0` | `front == rear && tag == 1` | 满时 $M$，空时 0 |

## 3. 特殊矩阵压缩存储映射公式（行优先，下标从 0 开始）

- **对称矩阵 ($n \times n$ 下三角)**：
  $$k = \frac{i(i + 1)}{2} + j \quad (i \ge j)$$
- **三对角矩阵**：第 $i$ 行非零元素在数组中的起始下标 $k = 2i + j$。
