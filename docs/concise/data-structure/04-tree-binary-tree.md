## 1. 二叉树 5 大核心数学性质

1. **叶子节点与双分支节点关系（必考）**：在任何非空二叉树中，度为 0 的叶子节点数 $n_0$ 与度为 2 的节点数 $n_2$ 满足：
   $$n_0 = n_2 + 1$$
2. **总节点数与边数关系**：$n = n_0 + n_1 + n_2 = \sum \text{各度节点数}$；总边数 $B = n - 1 = n_1 + 2n_2$；
3. 第 $i$ 层上最多有 $2^{i-1}$ 个节点；
4. 深度为 $k$ 的二叉树最多有 $2^k - 1$ 个节点（满二叉树）；
5. 具有 $n$ 个节点的完全二叉树深度为 $\lfloor \log_2 n \rfloor + 1$ 或 $\lceil \log_2(n + 1) \rceil$。

## 2. 哈夫曼树 (Huffman Tree) 与前缀编码

::: info 💡 哈夫曼树构造与 WPL 计算
1. **构造准则**：每次从集合中选出**权值最小的两个根节点**合并为一棵新二叉树，新树根权值为两子节点权值之和，重复此步骤直至只剩一棵树；
2. **节点特征**：哈夫曼树中**只有度为 0 的叶子节点和度为 2 的分支节点，绝对不存在度为 1 的节点 ($n_1 = 0$)**；
   - 含有 $n$ 个叶子节点的哈夫曼树总节点数 $N = 2n - 1$；
3. **带权路径长度 (WPL)**：
   $$\text{WPL} = \sum_{i=1}^n (w_i \times l_i) = \sum \text{所有非叶子分支节点的权值之和}$$
4. **哈夫曼编码**：向左分支标 0，向右分支标 1，从根到叶子的路径即为字符编码。满足**前缀编码**（无任何码字是其他码字的前缀），解码无二义性。
:::
