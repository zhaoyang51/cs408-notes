## 1. B 树 (多路平衡查找树) vs B+ 树核心区别

| 特性维度 | $m$ 阶 B 树 (B-Tree) | $m$ 阶 B+ 树 |
|:---|:---|:---|
| **关键字与子树数量** | 节点有 $k$ 个子树，必含 **$k - 1$ 个关键字** | 节点有 $k$ 个子树，必含 **$k$ 个关键字** |
| **根节点关键字范围** | $[1, \; m - 1]$（若非叶根节点至少 2 棵子树） | $[1, \; m]$（非叶根节点至少 2 棵子树） |
| **非根非叶关键字范围** | **$[\lceil m/2 \rceil - 1, \; m - 1]$** | **$[\lceil m/2 \rceil, \; m]$** |
| **数据记录存放位置** | 所有非叶节点和叶子节点均存放关键字与数据指针 | **只有最底层的叶子节点存放数据**，非叶节点仅作索引 |
| **叶子节点指针链接** | 叶子节点互不相连 | **所有叶子节点通过指针链接成一条有序双向链表** |
| **查找支持** | 仅支持从根向下单向查找 | **既支持随机查找，又支持顺叶子链表范围顺序遍历** |

## 2. 平衡二叉树 (AVL) 4 种旋转调整

- **平衡因子**：左子树深度 - 右子树深度（合法取值 $-1, 0, 1$）；
- **LL 旋转 (右单旋)**：在不平衡节点的左孩子的左子树插入 ➔ 右单旋；
- **RR 旋转 (左单旋)**：在右孩子的右子树插入 ➔ 左单旋；
- **LR 旋转 (先左后右双旋)**：在左孩子的右子树插入 ➔ 左孩子左旋，自身右旋；
- **RL 旋转 (先右后左双旋)**：在右孩子的左子树插入 ➔ 右孩子右旋，自身左旋。
