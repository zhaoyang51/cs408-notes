## 1. I/O 软件 4 层层次结构

```
 [1. 用户层 I/O 软件]   ----> 提供系统调用库函数 (printf, scanf, write, read)
         ⬇
 [2. 设备独立性软件]   ----> 逻辑设备名映射到物理设备名 (LUT)、设备保护、缓冲区管理
         ⬇
 [3. 设备驱动程序]     ----> 直接面向硬件控制器，设置寄存器，发送具体硬件读写指令
         ⬇
 [4. 中断处理程序]     ----> 响应硬件 I/O 中断信号，保存恢复现场，唤醒等待进程
         ⬇
    (物理硬件设备)
```

## 2. SPOOLing 假脱机技术核心原理

::: info 💡 SPOOLing 核心四要素
1. **输入井与输出井**：在**磁盘**上开辟的存储区域，暂存输入设备送来的数据和进程待输出的数据；
2. **输入缓冲区与输出缓冲区**：在**内存**中开辟的缓冲区，作为设备与磁盘井之间的数据中转；
3. **输入进程与输出进程**：模拟脱机外围控制机，在后台异步完成数据传输；
4. **技术核心价值**：**将物理上的独占设备（如打印机）改造为逻辑上供多个进程并发共享的虚拟设备**。
:::

## 3. 单缓冲 vs 双缓冲工作耗时计算公式

设从磁盘读入一块数据到缓冲区耗时 $T$，将缓冲区数据传送到用户工作区耗时 $M$，CPU 处理该数据块耗时 $C$：
- **单缓冲区处理 $N$ 个数据块总时间**：
  $$\text{总耗时} = (N - 1) \times \max(C, \; T) + M + T + C$$
  （连续处理时每块平均耗时 $= \max(C, \; T) + M$）
- **双缓冲区处理 $N$ 个数据块总时间**：
  $$\text{总耗时} = (N - 1) \times \max(C + M, \; T) + T + M + C$$
  （当 $T > C + M$ 时，设备满负荷运转；当 $C + M > T$ 时，CPU 满负荷运转）。
