## 1. 文件 3 大物理分配方式对比

| 物理分配方式 | 存储块分配特征 | 文件读写支持模式 | 扩充文件能力 | 空间利用率 / 碎片 |
|:---|:---|:---|:---:|:---|
| **连续分配** | 每个文件占用磁盘上一组**连续的物理块** | **支持顺序存取与随机直接存取** | 极差（难以预估大小） | 产生严重的**外部碎片** |
| **链接分配 (隐式)** | 目录项只记录首块号，每块存下一块指针 | **仅支持顺序存取**，不支持随机存取 | 极佳 | 稳定性差（指针损坏导致数据丢失） |
| **链接分配 (显式 FAT)** | 指针显式集中存放在**文件分配表 (FAT)** 中 | **支持顺序与随机存取**（检索 FAT 极快） | 极佳 | FAT 需占用常驻内存空间 |
| **索引分配** | 为每个文件建立索引块，记录该文件的物理块号表 | **支持随机存取**，多级索引容量极大 | 极佳 | 索引块需占用额外存储空间 |

## 2. 磁盘调度算法全景对比

| 调度算法 | 磁头移动决策准则 | 优点 | 缺点 / 饥饿 |
|:---|:---|:---|:---|
| **先来先服务 (FCFS)** | 按请求到达先后顺序调度 | 绝对公平 | 平均寻道距离极大 |
| **最短寻道时间 (SSTF)** | 优先调度距当前磁头最近的柱面磁道 | 寻道性能优于 FCFS | 产生**磁臂黏着与饥饿**现象 |
| **扫描算法 (SCAN / 电梯)** | 沿固定方向移动，途中响应，直到最外/内侧才掉头 | 寻道性能好，消除饥饿 | 对两端磁道响应不均 |
| **循环扫描 (C-SCAN)** | 仅在单向移动时响应请求，快速直接返回起点不响应 | 各磁道响应时间更均匀 | 寻道总距离略长于 SCAN |
| **LOOK / C-LOOK** | 到达**该方向上最后一个请求磁道即掉头**，不到端点 | 避免移动到无请求的磁盘最边缘 | 408 实际应用最广泛优化版 |
