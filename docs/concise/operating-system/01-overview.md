## 1. 操作系统 4 大核心特征

| 特征 | 核心物理定义 | 相互依存关系 |
|:---|:---|:---|
| **1. 并发 (Concurrency)** | 两个或多个事件在**同一时间间隔**内发生（宏观同时，微观交替） | **并发与共享是操作系统最基本的两个特征**，互为存在前提 |
| **2. 共享 (Sharing)** | 系统中的资源供内存中多个并发执行的进程共同使用（互斥共享 vs 同时共享） | 资源共享以程序的并发执行为条件 |
| **3. 虚拟 (Virtual)** | 把一个物理实体变为若干个逻辑上的对应物（时分复用 CPU / 空分复用虚存） | 没有并发性，则虚拟性毫无意义 |
| **4. 异步 (Asynchrony)** | 进程以不可预知的速度向前推进（走走停停） | 只要运行环境相同，OS 保证进程执行结果具有确定性 |

## 2. 内核态 (管态) vs 用户态 (目态) 与系统调用

| 状态维度 | 用户态 (目态 / User Mode) | 内核态 (管态 / Kernel Mode) |
|:---|:---|:---|
| **特权级别** | 低特权级，只能执行**非特权指令** | 最高特权级，可以执行**特权指令与所有非特权指令** |
| **指令范围** | 算术运算、访存读取、逻辑跳转 | 关中断、修改 PSW、设置时钟、I/O 指令、清内存 |
| **状态转换方向** | **用户态 ➔ 内核态**：**唯一途径是通过中断 / 异常 / 硬件陷阱 (Trap)** | **内核态 ➔ 用户态**：执行修改程序状态字 PSW 的**特权指令 (如中断返回 IRET)** |

::: tip 💡 系统调用的完整触发流程
用户程序执行**访管指令（Trap / 陷入指令 / int 80h）** ➔ CPU 硬件自动转入内核态 ➔ 执行中断向量引出的系统调用处理程序 ➔ 内核完成核心服务 ➔ 恢复现场并返回用户态。
:::
