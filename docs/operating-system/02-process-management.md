# 二、进程管理

> 本章包含考点小节：4 个

# （一）进程与线程

## 进程与线程

### 1. 进程的概念、特征与组成

- **进程概念**：进程是程序在某个数据集合上的一次运行活动，是系统进行资源分配和调度的独立单位（在引入线程后，是资源分配的基本单位）。

- **组成**：PCB（进程控制块，进程存在的唯一标志）、程序段、数据段。

- **特征**：动态性（最基本特征）、并发性、独立性、异步性、结构性。

### 2. 进程的状态与转换

- **五状态模型**：创建态、就绪态（Ready）、运行态（Running）、阻塞态（Waiting/Blocked）、结束态。

- 状态转换：就绪->运行（进程调度）；运行->就绪（时钟中断/时间片用完）；运行->阻塞（请求资源/I/O操作）；阻塞->就绪（等待事件完成）。（注：阻塞态不能直接转为运行态）。

### 3. 进程控制与原语

- 进程创建（fork）、终止、阻塞（block）、唤醒（wakeup）。原语利用关中断和开中断实现原子操作。

### 4. 进程通信（IPC）

- **共享存储**：低级基于数据结构共享，高级基于共享内存区（如 shmget/shmat）。

- **消息传递**：直接通信（原语 send/receive 挂入目标 PCB 消息队列）与间接通信（信箱通信）。

- **管道通信（Pipe）**：半双工通信，基于特殊共享文件，具有缓冲区限制及互斥同步读写机制。

### 5. 线程概念与多线程模型

- **线程**：轻量级进程（LWP），是 CPU 调度的基本单位，共享所属进程的代码段、数据段和打开文件，拥有独立的栈和寄存器上下文。

- **用户级线程（ULT）与内核级线程（KLT）**。

- **多对一、一对一、多对多模型**。

# （二）处理机调度

## 处理机调度

### 1. 调度的层次

- 高级调度（作业调度，从外存后备队列调入内存）、中级调度（内存调度，挂起与激活）、低级调度（进程调度，频率最高）。

### 2. 调度指标

- CPU 利用率、系统吞吐量、周转时间（完成时间 - 提交时间）、带权周转时间（周转时间 / 实际运行时间）、等待时间、响应时间。

### 3. 典型调度算法

- **FCFS（先来先服务）**：非抢占，对长作业有利，对短作业不利（护航效应）。

- **SJF/SPF（短作业/短进程优先）**：平均周转时间和平均等待时间最短，但可能导致饥饿。

- **HRRN（高响应比优先）**：响应比 R = (等待时间 + 运行时间) / 运行时间，兼顾长短作业。

- **时间片轮转（RR）**：抢占式，时间片大小权衡。

- **优先级调度算法**：非抢占/抢占式；静态优先级与动态优先级。

- **多级反馈队列（MFQ）**：多级就绪队列，时间片自上而下递增，新进程入首队列，降级惩罚，综合性能最优。

# （三）同步与互斥

## 同步与互斥

### 1. 基本概念

- **临界资源**：一次仅允许一个进程使用的资源。

- **临界区**：访问临界资源的代码段。

- **同步机制 4 大准则**：空闲让进、忙则等待、有限等待、让权等待。

### 2. 实现互斥的基本方法

- **软件方法**：单标志法（违背空闲让进）、双标志先检查法（违背忙则等待）、双标志后检查法（可能产生死锁）、Peterson 算法（满足前三准则，未满足让权等待）。

- **硬件方法**：关中断、TestAndSet（TSL 指令）、Swap/XCHG 指令。

### 3. 信号量机制（Semaphore）

- **整型信号量**：wait(S) 和 signal(S)（P/V 操作），未实现让权等待。

- **记录型信号量**：包含 value 和 wait_list 队列。P 操作（S.value--，< 0 阻塞自我并让权）；V 操作（S.value++，<= 0 唤醒等待队列进程）。

### 4. 管程（Monitor）

- 共享数据结构与一组操作构成的软件模块，由编译器保证互斥，引入条件变量（condition）配合 wait/signal。

### 5. 经典同步互斥问题

- 生产者-消费者问题、读者-写者问题（读优先 vs 写优先）、哲学家进餐问题（防死锁破坏循环等待）、吸烟者问题。

# （四）死锁

## 死锁

### 1. 死锁的概念与产生的 4 个必要条件

- **互斥条件**：资源互斥使用。

- **不剥夺条件（非抢占）**：已获得的资源未使用完前不能被强行剥夺。

- **请求并保持条件**：保持已有资源同时请求新资源。

- **循环等待条件**：存在进程-资源的环形等待链。

### 2. 死锁处理策略

- **死锁预防**：破坏 4 个必要条件之一（破坏互斥、破坏不剥夺、一次性分配破坏请求并保持、按序分配破坏循环等待）。

- **死锁避免**：安全状态与不安全状态（不安全状态 != 死锁）；**银行家算法（Banker's Algorithm）** 计算安全性序列。

- **死锁检测与解除**：资源分配图化简（死锁定理）；死锁解除方法（资源剥夺法、撤销进程法、进程回退法）。
