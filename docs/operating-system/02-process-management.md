# 第2章 进程线程、调度与死锁

## 1. 进程状态转换（经典 5 状态）

- **就绪 $\rightarrow$ 运行**：获得 CPU 时间片。
- **运行 $\rightarrow$ 就绪**：时间片用完或被更高优先级抢占。
- **运行 $\rightarrow$ 阻塞**：主动请求资源（如 I/O、等待信号量 $P$ 操作）。
- **阻塞 $\rightarrow$ 就绪**：等待的事件发生（被动唤醒）。

## 2. 经典 CPU 调度算法

| 算法 | 是否抢占 | 优点 | 缺点 / 饥饿 |
|:---|:---:|:---|:---|
| **FCFS (先来先服务)** | 非抢占 | 简单公平 | 对长作业有利，对短作业不利（护航效应） |
| **SJF / SPF (短作业优先)** | 均可 | **平均等待时间最短** | 会导致长作业 **饥饿** |
| **HRRN (高响应比优先)** | 非抢占 | 兼顾长短作业 | 响应比 $R = \frac{\text{等待时间} + \text{服务时间}}{\text{服务时间}}$ |
| **RR (时间片轮转)** | 抢占 | 响应速度快 | 时间片太大退化为 FCFS，太小切换开销大 |
| **多级反馈队列** | 抢占 | 兼顾各类作业，408 综合最优 | 无需事先预估执行时间 |

## 3. 死锁产生与避免（银行家算法）

- **死锁 4 大必要条件**：互斥、不剥夺、请求并保持、循环等待。
- **银行家算法核心**：寻找安全序列（安全性检查算法：若存在安全序列则系统处于安全状态，绝无死锁）。
