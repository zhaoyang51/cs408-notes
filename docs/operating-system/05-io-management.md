## 1. I/O 软件 4 层结构

1. **用户层 I/O 软件**：提供库函数 API（如 `printf`、`scanf`）。
2. **设备独立性软件**：逻辑设备名到物理设备名的映射 (LUT 表)、缓冲池管理、设备保护。
3. **设备驱动程序**：向设备控制器寄存器发出特定读写指令。
4. **中断处理程序**：响应硬件设备完成中断。

---

## 2. SPOOLing 假脱机技术

- **核心思想**：利用高速共享磁盘存储空间，将**独占设备（如打印机）虚拟为多台逻辑共享设备**。
- **核心组件**：输入井/输出井（外存磁盘上）、输入进程/输出进程（内存中）。
