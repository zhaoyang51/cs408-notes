# 五、输入/输出（I/O）管理

> 本章包含考点小节：2 个

---

# （一）I/O 管理概述

## I/O 管理概述

### 1. I/O 设备分类

- 人机交互设备 vs 外部存储设备；块设备（如磁盘，有结构，可寻址） vs 字符设备（如键盘、打印机，无结构，不可寻址）。

### 2. I/O 控制方式

- 程序直接控制方式（轮询）、中断驱动方式、DMA 方式、通道控制方式（通道程序/通道指令）。

### 3. I/O 软件层次结构

- 用户层 I/O 软件 -> 设备独立性软件（逻辑设备名到物理设备名映射 LUT、设备保护、缓冲区管理） -> 设备驱动程序 -> 中断处理程序 -> 硬件。


---

# （二）I/O 核心子系统

## I/O 核心子系统

### 1. I/O 调度与设备分配

- 设备分配的数据结构：DCT（设备控制表）、COCT（控制器控制表）、CHCT（通道控制表）、SDT（系统设备表）。

- 设备独立性（逻辑设备表 LUT 实现设备无关性）。

### 2. 高速缓存与缓冲区管理

- 单缓冲、双缓冲（处理时间 max(C, T) + M）、循环缓冲、缓冲池（收容/提取队列与空闲队列）。

### 3. SPOOLing 技术（假脱机技术）

- **组成**：输入井与输出井（磁盘区）、输入缓冲区与输出缓冲区（内存区）、输入进程与输出进程。

- **实质**：将独占设备改造为共享设备，实现虚拟设备。
