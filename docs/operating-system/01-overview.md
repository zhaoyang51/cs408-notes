## 1. 操作系统 4 大核心特征

- **并发**：同一时间间隔内多个进程推进（最基本特征，互为虚拟和异步的前提）。
- **共享**：互斥共享（如临界资源打印机）与同时访问共享（如磁盘文件）。
- **虚拟**：时分复用（虚拟 CPU）与空分复用（虚拟内存）。
- **异步**：多道程序环境下进程以不可预知的速度向前推进。

## 2. 内核态 vs 用户态与系统调用

| 状态类型 | CPU 执行特权 | 允许执行的指令集 | 典型应用 |
|:---|:---|:---|:---|
| **内核态 (管态)** | 最高特权级（Ring 0） | 特权指令（清内存、关中断、I/O 指令）与非特权指令 | 操作系统内核服务 |
| **用户态 (目态)** | 低特权级（Ring 3） | **仅允许非特权指令** | 普通用户应用程序 |

- **用户态 → 内核态**：**唯一途径是通过中断 / 异常 / 系统调用**（由硬件中断机制强制触发）。
- **内核态 → 用户态**：通过修改程序状态字 PSW 特权指令主动降级返回。

## 3. 操作系统 4 大核心功能模块与关键机制

<KP author="Chen" title="操作系统四大核心功能模块与关键技术全景" tag="💡 408 全景知识结构">

| 功能模块 | 核心职责 | 关键技术与机制 |
|:---|:---|:---|
| **处理器管理**<br>*(Processor Management)* | 控制和管理 CPU 的运行，协调多任务的高效并发执行。 | • **进程与线程调度**（时间片轮转、优先级调度、多级反馈队列）<br>• **进程同步与互斥**（信号量机制、管程）<br>• **进程间通信 (IPC)**<br>• **死锁的预防、避免（银行家算法）、检测与解除** |
| **存储器管理**<br>*(Memory Management)* | 分配、回收和保护主存空间，最大化内存的利用率。 | • **虚拟内存机制**（请求分页、请求分段、段页式管理）<br>• **地址映射**（逻辑地址/虚拟地址 → 物理地址，TLB 快表加速）<br>• **内存扩充与页面置换算法**（OPT、FIFO、LRU、CLOCK 置换算法） |
| **设备管理**<br>*(Device Management)* | 响应和处理所有外围 I/O 设备的请求，实现对应用程序的“硬件透明性”。 | • **缓冲技术**（单/双/循环缓冲，缓解 CPU 与外部设备间的速度差异）<br>• **中断处理与 DMA 直接内存访问**<br>• **设备驱动程序封装与设备独立性**<br>• **虚拟设备与池化技术**（SPOOLing 假脱机技术） |
| **文件管理**<br>*(File Management)* | 组织、存储、保护和检索非易失性存储介质（如磁盘）上的数据资源。 | • **文件目录结构管理**（多级树形目录、FCB 文件控制块）<br>• **文件存取与读写权限控制**（存取控制矩阵/ACL）<br>• **物理存储空间动态分配**（连续分配、链接分配、索引分配 / UNIX Inode 结构、FAT 表） |
