# （一）操作系统的概念、特征、功能和提供的服务

## 操作系统的概念、特征、功能和提供的服务

### 1. 操作系统的概念

- 控制和管理整个计算机系统的硬件和软件资源，合理组织调度计算机的工作与资源分配，并向用户和其他软件提供方便接口与环境的程序集合。

### 2. 操作系统的 4 个基本特征

- **并发（Concurrence）**：同一时间间隔内发生两个或多个事件（与并行 Parallel 区分）。并发性是操作系统最基本的特征。

- **共享（Sharing）**：系统中的资源供内存中多个并发执行的进程共同使用。分为互斥共享（如临界资源、打印机）和同时访问共享（如磁盘、可重入代码）。

- **虚拟（Virtual）**：把一个物理实体变为若干个逻辑上的对应物（时分复用如虚拟处理器，空分复用如虚拟内存）。

- **异步（Asynchronism）**：进程以不可预知的速度向前推进。

### 3. 操作系统的主要功能

- 处理机管理、存储器管理、设备管理、文件管理、提供用户接口。

### 4. 提供的服务

- 命令接口（联机命令/脱机命令）、程序接口（系统调用）、GUI 接口。

# （二）操作系统的发展与分类

## 操作系统的发展与分类

- **手工操作阶段**：用户独占全机，CPU 等待手工操作，资源利用率极低。

- **单道批处理系统**：自动性、顺序性、单道性，缺少交互性。

- **多道批处理系统**：多道、宏观上并行、微观上串行，资源利用率高，但响应时间长、无交互。

- **分时操作系统**：同时性、交互性、独立性、及时性（时间片轮转）。

- **实时操作系统**：高可靠性与及时性（硬实时与软实时）。

- **网络与分布式操作系统**。

# （三）操作系统的运行环境

## 操作系统的运行环境

### 1. 运行机制

- **内核程序与用户程序**。

- **核心态（管态/Kernel Mode）与用户态（目态/User Mode）**：PSW 标志位切换。

- **特权指令与非特权指令**：清内存、置 PSW、I/O 指令等为特权指令，只能在核心态执行。

### 2. 中断和异常机制

- **中断（外中断）**：来自 CPU 执行指令以外的事件（如时钟中断、I/O 结束中断）。

- **异常（内中断）**：来自 CPU 执行指令内部的事件（如非法操作码、地址越界、缺页、除零、系统调用）。

- **中断处理与现场保护**：硬件自动保存 PC 和 PSW，转入相应中断服务例程。

### 3. 系统调用

- **概念**：用户在程序中调用操作系统所提供的一些子功能（运行在核心态）。

- **系统调用过程**：用户态传递参数 -> 执行软中断/陷阱指令（如 int 0x80 / syscall） -> CPU 陷入核心态 -> 执行系统调用内核函数 -> 返回用户态。

# （四）操作系统结构

## 操作系统结构

- **分层结构**：低层为高层提供单向调用接口，易于调试维护，但调用效率低。

- **模块化结构**：模块独立性高，便于并行开发，但模块间接口划分复杂。

- **微内核结构**：仅把最基本功能（进程通信、时钟中断、底层硬件抽象）保留在内核态，其余功能作为用户态服务器实现。可靠性高、易扩展，但上下文切换开销大。

- **外核结构（Exokernel）**：外核仅负责保护资源分配，将资源管理抽象下放给应用层。

# （五）操作系统引导（Booting）

## 操作系统引导（Booting）

- **引导全过程**：

- ① CPU 加电，从 ROM 中读取执行 BIOS/UEFI 初始化程序并进行硬件自检（POST）。

- ② BIOS 读取启动盘的主引导记录（MBR）并载入内存。

- ③ MBR 执行引导扇区代码，寻找活动分区的引导记录（PBR/VBR）。

- ④ 读取根目录下的操作系统引导加载程序（如 GRUB / Windows Boot Manager）。

- ⑤ 引导程序将操作系统内核程序加载至内存并初始化，移交 CPU 控制权。

# （六）虚拟机（Virtual Machine）

## 虚拟机（Virtual Machine）

- **Hypervisor（虚拟机管理程序 VMM）分类**：

- **Type 1（裸金属型 Hypervisor）**：直接运行在裸机硬件之上，具有最高特权级（如 VMware ESXi, Xen）。

- **Type 2（宿主型 Hypervisor）**：运行在宿主操作系统之上，作为普通进程（如 VMware Workstation, VirtualBox）。

- **硬件虚拟化支持**：Intel VT-x / AMD-V 提供 Root 模式与 Non-Root 模式。
