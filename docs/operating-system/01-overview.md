## 1. 操作系统 4 大核心特征

- **并发**：同一时间间隔内多个进程推进（最基本特征，互为虚拟和异步的前提）。
- **共享**：互斥共享（如临界资源打印机）与同时访问共享（如磁盘文件）。
- **虚拟**：时分复用（虚拟 CPU）与空分复用（虚拟内存）。
- **异步**：多道程序环境下进程以不可预知的速度向前推进。

## 2. 内核态 vs 用户态与系统调用

| 状态类型 | CPU 执行特权 | 允许执行的指令集 | 典型应用 |
|:---|:---|:---|:---|
| **内核态 (管态)** | 最高特权级（Ring 0） | 特权指令（清内存、关中断、I/O 指令）与非特权指令 | 操作系统内核服务 |
| **用户态 (目态)** | 低特权级（Ring 3） | **仅允许非特权指令** | 普通用户应用程序 |

- **用户态 → 内核态**：**唯一途径是通过中断 / 异常 / 系统调用**（由硬件中断机制强制触发）。
- **内核态 → 用户态**：通过修改程序状态字 PSW 特权指令主动降级返回。

## 4. 操作系统引导 (Booting) 7 步全流程

<KP author="Chen" title="操作系统加电启动与引导全流程 (BIOS → MBR → PBR → OS)" tag="⭐️ 命题高频">

| 顺序 | 核心步骤 | 详细执行机制 (408 核心考点) |
|:---:|:---|:---|
| **1** | **激活 CPU** | 计算机通电后，CPU 的程序计数器（PC）被硬件逻辑强制置为一个特定的物理地址。这个地址直接指向主板 ROM 中的 BIOS（基本输入输出系统）程序的第一条指令。 |
| **2** | **硬件自检 (POST)** | CPU 开始执行 BIOS 程序，首先进行加电自检（Power-On Self Test），检查内存、显卡等核心硬件是否存在致命故障。 |
| **3** | **确定启动设备** | BIOS 读取 CMOS 中的非易失性配置信息，判断并确定启动设备的优先级顺序（例如默认从哪一块硬盘启动）。 |
| **4** | **加载主引导记录 (MBR)** | BIOS 锁定启动硬盘后，将该硬盘的绝对第一个物理扇区（即主引导扇区，内部包含主引导程序和磁盘分区表 DPT）完整读取到 RAM 中，并将 CPU 控制权正式移交给 MBR 中的主引导程序。 |
| **5** | **定位活动分区** | MBR 中的主引导程序开始执行，它会扫描刚才读入内存的磁盘分区表 (DPT)，在其中寻找标志为“活动 (Active)”状态的分区（即当前安装操作系统的分区）。 |
| **6** | **加载分区引导记录 (PBR)** | 锁定活动分区后，主引导程序会将该活动分区的第一个扇区（即分区引导块/引导扇区，包含分区引导程序 PBR）读入 RAM，并将控制权交接给 PBR。 |
| **7** | **加载 OS 内核程序** | PBR 分区引导程序利用文件系统机制，在该分区的根目录中寻找操作系统初始化程序（即内核装载程序/Bootloader）。将其读入 RAM 并执行后，由它负责把完整的 OS 内核装载进内存并完成各项初始化。至此，引导结束，OS 正式接管系统。 |

::: tip 💡 408 极速速记链
**通电置 PC(ROM BIOS) → 硬件自检 POST → 读 CMOS 选盘 → 载 MBR 查 DPT → 定位活动分区 → 载 PBR → 运行 Bootloader 装载内核入 RAM**
:::

</KP>
