# 第1章 操作系统概述与体系结构

## 1. 操作系统 4 大基本特征

- **并发**：同一时间间隔内多个任务推进（最基本特征）。
- **共享**：互斥共享（临界资源）与同时访问共享。
- **虚拟**：时分复用（虚拟 CPU）与空分复用（虚拟内存）。
- **异步**：进程以不可预知的速度向前推进。

---

## 2. 内核态 vs 用户态

- **内核态（管态）**：执行特权指令（如关中断、I/O 指令、清内存），访问所有资源。
- **用户态（目态）**：执行非特权指令，只能访问用户空间。
- **切换途径**：用户态 $\rightarrow$ 内核态 **唯一途径是中断/异常/系统调用**；内核态 $\rightarrow$ 用户态通过修改 PSW。
