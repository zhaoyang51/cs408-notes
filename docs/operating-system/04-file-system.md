# 第4章 文件系统与磁盘调度

## 1. 文件物理分配方式

- **连续分配**：支持顺序存取与随机存取，但有外部碎片且文件拓展困难。
- **链接分配**：隐式链接只支持顺序存取；显式链接 (FAT 表) 支持随机存取。
- **索引分配 (如 UNIX inode)**：多级索引（直接索引 + 一级间接 + 二级间接 + 三级间接）。

---

## 2. 磁盘调度算法

- **FCFS**：按请求顺序访问。
- **SSTF (最短寻道时间优先)**：优先访问离当前磁头最近的磁道（可能引起饥饿）。
- **SCAN (电梯调度算法)**：单向移动到头再折返。
- **C-SCAN (循环扫描)**：单向扫描到底后立即返回最前端重新开始。
