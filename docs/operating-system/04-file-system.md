# 四、文件管理

> 本章包含考点小节：3 个

---

# （一）文件系统基础

## 文件系统基础

### 1. 文件的基本概念与逻辑结构

- **无结构文件（流式文件）**：字节流。

- **有结构文件（记录式文件）**：顺序文件、索引文件、索引顺序文件。

### 2. 目录结构

- **文件控制块（FCB）** 与 **索引结点（inode）**（减小目录项大小，加速目录检索）。

- 单级目录、两级目录、树形目录结构（绝对路径与相对路径）、无环图目录结构（实现文件共享）。

### 3. 文件共享与保护

- **基于硬链接的共享（索引结点计数器 count）**：删除文件仅让 count--，count=0 时真正释放空间。

- **基于符号链接（软链接/快捷方式）的共享**：存放目标文件路径，目标删除后成为死链接。

- **文件保护**：访问控制列表（ACL）、口令保护、加密保护。

# （二）文件系统实现

## 文件系统实现

### 1. 文件系统层次结构

- 用户接口 -> 文件目录系统 -> 存取控制模块 -> 逻辑文件系统与缓冲区 -> 物理文件系统 -> 设备管理程序。

### 2. 文件的物理结构（外存分配方式）

- **连续分配**：支持随机存取，顺序访问快，但有外部碎片且不易动态扩展。

- **隐式链接分配**：指针存放在盘块中，只支持顺序存取；**显式链接分配（FAT 文件分配表）**：支持随机存取。

- **索引分配**：单级索引、多级索引、混合索引（如 UNIX inode：直接块 + 一级间接块 + 二级间接块 + 三级间接块，计算文件最大支持容量）。

### 3. 存储空间管理（空闲盘块管理）

- 空闲表法、空闲链表法、位示图法（Bitmap，字长与行列计算公式）、成组链接法（UNIX 广泛使用）。

# （三）磁盘组织与管理

## 磁盘组织与管理

### 1. 磁盘调度算法

- **FCFS（先来先服务）**。

- **SSTF（最短寻道时间优先）**：产生饥饿。

- **SCAN（电梯调度算法）**：沿一个方向移动到最外/最内侧再折返。

- **C-SCAN（循环扫描）**：单向扫描，到达边界后快速回到起始端不服务。

- **LOOK 与 C-LOOK**：到达最外/最内侧请求后即折返。

### 2. 磁盘格式化与坏块管理

- 低级格式化（划分扇区）、逻辑格式化（建立文件系统元数据）。
