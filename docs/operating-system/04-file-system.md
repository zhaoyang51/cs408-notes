## 1. 文件物理结构对比

- **连续分配**：支持随机存取，但有外部碎片且不易扩充。
- **链接分配**：隐式链接仅支持顺序存取；显式链接 (FAT 表) 支持随机存取。
- **UNIX inode 多级索引结构**：直接索引 + 一级间接 + 二级间接 + 三级间接，极大扩展文件最大容量。

## 2. 磁盘调度算法

| 算法 | 移动磁头策略 | 优缺点 |
|:---|:---|:---|
| **FCFS (先来先服务)** | 按请求顺序依次寻道 | 公平，平均寻道距离长 |
| **SSTF (最短寻道时间优先)** | 优先处理离当前磁头最近的柱面 | 寻道效率高，**可能引起边缘柱面饥饿** |
| **SCAN (电梯调度算法)** | 沿一个方向扫描到头，再反向扫描 | 彻底消除饥饿，对两端请求有利 |
| **C-SCAN (循环扫描)** | 仅单向扫描，到底后立即返回起点重新扫描 | 消除了两端与中间请求的不均衡性 |
