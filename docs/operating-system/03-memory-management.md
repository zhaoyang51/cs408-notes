# 三、内存管理

> 本章包含考点小节：3 个

---

# （一）内存管理概念

## 内存管理概念

### 1. 内存管理的基本功能

- 内存空间的分配与回收、地址转换（地址重定位）、存储保护、内存空间扩充（虚拟内存）。

### 2. 程序装入与链接

- **链接方式**：静态链接、装入时动态链接、运行时动态链接。

- **装入方式**：绝对装入（编译产生绝对地址）、可重定位装入（静态重定位，装入时一次修改物理地址）、动态运行时装入（动态重定位，借助基址/重定位寄存器在执行时动态计算物理地址）。

### 3. 连续分配管理方式

- **单一连续分配**：单用户独占。

- **固定分区分配**：内部碎片（Internal Fragmentation）。

- **动态分区分配**：外部碎片（External Fragmentation，可通过紧凑/拼接技术消除）。

- **动态分区分配算法**：首次适应（First Fit，性能最好）、最佳适应（Best Fit，产生微小碎片）、最坏适应（Worst Fit）、邻近适应（Next Fit）。

# （二）非连续分配管理方式

## 非连续分配管理方式

### 1. 基本分页存储管理

- 页面（页号 P + 页内偏移 W）与物理块（页框）。页表记录页号到物理块号的映射。

- 逻辑地址到物理地址的转换：P = A / L, W = A % L；物理地址 = 物理块号 * L + W。

- 具有快表（TLB）的地址变换机构：TLB 命中一次访存，TLB 未命中两次访存。

- 两级及多级页表：解决单级页表占用过大连续内存空间问题。

### 2. 基本分段存储管理

- 按照程序逻辑划分段（段号 S + 段内地址 W）。段表记录段长与基址。

- 分页 vs 分段：页是物理单位（一维地址空间），段是逻辑单位（二维地址空间）。

### 3. 段页式存储管理

- 先分段再分页。逻辑地址：段号 + 段内页号 + 页内偏移。访存次数：未用 TLB 时需 3 次访存。

# （三）虚拟内存管理

## 虚拟内存管理

### 1. 虚拟内存的基本概念

- 局部性原理；虚拟内存特征：多次性、对换性、虚拟性。

### 2. 请求分页存储管理

- 请求页表机制（状态位/存在位 P、访问字段 A、修改位/脏位 M、外存地址）。

- 缺页中断机制：缺页中断属于内部异常（Fault），执行在指令执行周期中，需调入页面并重新执行该指令。

### 3. 页面置换算法

- **OPT（最佳置换算法）**：淘汰以后最长时间不再访问的页面（理论上限，无法实现）。

- **FIFO（先进先出）**：产生 **Belady 异常**（所分配物理块数增加，缺页次数反而增加）。

- **LRU（最近最久未使用）**：堆栈/计数器硬件支持，性能接近 OPT。

- **CLOCK（时钟置换/NRU 最近未用）**：使用标志位 0/1。

- **改进型 CLOCK 算法**：优先淘汰 (访问位, 修改位) 为 (0, 0)，其次 (0, 1)，再 (1, 0)，最后 (1, 1)。

### 4. 页面分配策略与抖动（颠簸）

- 固定分配局部置换、可变分配全局置换、可变分配局部置换。

- **抖动（Thrashing）**：频繁的页面调度导致 CPU 利用率急剧下降。原因：分配的物理块数不足。

- **工作集（Working Set）**：某段时间间隔内进程实际访问的页面集合。驻留集大小应大于工作集大小。
