# 第3章 内存管理与虚拟内存

## 1. 连续分配 vs 分页分段

- **基本分页**：页大小固定，**无外部碎片，有页内内部碎片**。
- **基本分段**：段长不固定，按逻辑分段，**无内部碎片，有外部碎片**。
- **两级/多级页表**：页表大小不能超过一个物理页面。

## 2. 虚拟内存页面置换算法

| 算法 | 置换策略 | 特点 |
|:---|:---|:---|
| **OPT (最佳置换)** | 淘汰以后永不使用或最长时期内不用的页面 | **理论最优**，无法实现 |
| **FIFO (先进先出)** | 淘汰最先进入内存的页面 | 会出现 **Belady 异常**（分配物理块增多但缺页率反升） |
| **LRU (最近最久未使用)** | 淘汰最近最长时间未访问的页面 | 性能最接近 OPT，开销较大 |
| **CLOCK (时钟置换)** | 使用访问位 $u$，循环指针扫描 | 实用折中方案（二次机会法结合修改位 $m$） |
