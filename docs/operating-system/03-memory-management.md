## 1. 连续分配 vs 离散分配机制

| 管理方式 | 碎片特性 | 地址转换机制 | 核心优缺点 |
|:---|:---|:---|:---|
| **基本分页** | **无外部碎片，有页内碎片** | 逻辑地址 → 页号 + 页内偏移 | 内存利用率高，无逻辑独立性 |
| **基本分段** | **无内部碎片，有外部碎片** | 逻辑地址 → 段号 + 段内偏移 | 方便代码共享与保护，易产生碎片 |
| **段页式管理** | 无外部碎片，仅段内最后一页有内部碎片 | 段号 → 段表 → 页表 → 物理块 | 综合优势，访存开销大（需 3 次访存） |

## 2. 4 大页面置换算法性能对比

| 置换算法 | 淘汰策略 | 算法特点与异常 |
|:---|:---|:---|
| **OPT (最佳置换)** | 淘汰以后永不使用或最长时期内不用的页面 | **理论上限**，无法实现 |
| **FIFO (先进先出)** | 淘汰最早进入内存的驻留页面 | 会产生 **Belady 异常**（分配物理块数增多但缺页率反增） |
| **LRU (最近最久未使用)** | 淘汰最近最长时间未被访问的页面 | 性能最接近 OPT，硬件开销大 |
| **CLOCK (时钟置换)** | 循环指针扫描，检查访问位 $u$ 与修改位 $m$ | 实际操作系统最常采纳的折中方案 |
