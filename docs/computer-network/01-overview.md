# 第1章 计算机网络体系结构

## 1. 网络性能指标核心计算公式

$$\text{总时延} = \text{发送时延 (传输时延)} + \text{传播时延} + \text{处理时延} + \text{排队时延}$$

$$\text{发送时延} = \frac{\text{数据长度 (bit)}}{\text{信道带宽 (b/s)}}$$

$$\text{传播时延} = \frac{\text{信道长度 (m)}}{\text{电磁波传播速率 (m/s)}} \quad (\text{光纤/铜线通常取 } 2 \times 10^8 \text{ m/s})$$

$$\text{时延带宽积} = \text{传播时延} \times \text{信道带宽 (以 bit 为单位)}$$

## 2. ISO/OSI 7 层 vs TCP/IP 4 层

| OSI 7 层模型 | TCP/IP 4 层模型 | 协议数据单元 (PDU) | 典型协议 |
|:---|:---|:---:|:---|
| **应用层 / 表示层 / 会话层** | **应用层** | 报文 (Message) | HTTP, DNS, FTP, SMTP |
| **传输层** | **传输层** | 报文段 / 数据报 | TCP, UDP |
| **网络层** | **网络层 (网际层)** | IP 数据报 / 分组 | IP, ICMP, ARP, OSPF |
| **数据链路层** | **网络接口层** | 帧 (Frame) | 以太网, PPP |
| **物理层** | **网络接口层** | 比特 (Bit) | RJ45, 光纤 |
