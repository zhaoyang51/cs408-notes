# （一）计算机网络概述

## 计算机网络概述

### 1. 计算机网络的概念、组成与功能

- **概念**：互联的、自治的计算机系统的集合。

- **组成**：组成部分（硬件、软件、协议）；工作方式（边缘部分：C/S 方式与 P2P 方式；核心部分：路由器、网络交换）；功能组成（通信子网、资源子网）。

- **功能**：数据通信（最基本功能）、资源共享、分布式处理、信息综合服务。

### 2. 计算机网络的分类

- 按分布范围：广域网（WAN）、城域网（MAN）、局域网（LAN）、个人区域网（PAN）。

- 按拓扑结构：总线形、星形、环形、网状形。

- 按交换技术：电路交换、报文交换、分组交换（数据报与虚电路）。

# （二）计算机网络性能指标

## 计算机网络性能指标

- **速率与带宽**：速率（b/s, kb/s, Mb/s, Gb/s），带宽（信道最高数据率）。

- **吞吐量（Throughput）**：单位时间内通过某个网络（或信道、接口）的实际数据量。

- **时延（Delay）**：总时延 = 发送时延（数据长度/信道带宽） + 传播时延（信道长度/电磁波传播速率 2*10^8 m/s） + 处理时延 + 排队时延。

- **时延带宽积**：传播时延 * 带宽（以位为单位的链路链路容量）。

- **往返时间（RTT）** 与 **信道利用率**。

# （三）计算机网络体系结构与参考模型

## 计算机网络体系结构与参考模型

### 1. 体系结构概念

- 协议（语法、语义、同步三要素）、接口与服务（服务访问点 SAP）。面向连接与无连接服务。

### 2. ISO/OSI 参考模型（7层）

- 物理层、数据链路层、网络层、传输层、会话层、表示层、应用层。

### 3. TCP/IP 参考模型（4层）

- 网络接口层、网际层（IP）、传输层（TCP/UDP）、应用层。

### 4. 2026 大纲改动考点对比

- 掌握 5 层体系结构各层协议数据单元（PDU）：物理层（比特 Bit）、数据链路层（帧 Frame）、网络层（分组/数据报 Packet/Datagram）、传输层（报文段/用户数据报 Segment/User Datagram）、应用层（报文 Message）。
