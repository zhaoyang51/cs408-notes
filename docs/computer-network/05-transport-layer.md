# 第5章 传输层 (TCP / UDP)

## 1. TCP vs UDP 核心区别

| 特性 | TCP | UDP |
|:---|:---|:---|
| 连接性 | **面向连接** | **无连接** |
| 可靠性 | **可靠交付** (确认、重传、排序、去重) | **尽最大努力交付** |
| 传输形式 | **字节流** | **报文** (保留边界) |
| 首部开销 | 20 字节起 | 固定 **8 字节** |

---

## 2. TCP 拥塞控制 4 部曲

1. **慢开始**：$cwnd$ 从 1 开始指数增长 ($1, 2, 4, 8...$)，直到达到门限 $ssthresh$。
2. **拥塞避免**：$cwnd$ 达到 $ssthresh$ 后加法线性增长（每轮 $+1$）。
3. **超时 (Timeout)**：$ssthresh$ 降为当前 $cwnd / 2$，$cwnd$ 重新置为 1。
4. **快重传与快恢复**：收到 3 个重复 ACK 立即重传，$ssthresh = cwnd / 2$，$cwnd = ssthresh$ 并进入拥塞避免。
