### 3.1 DHCP 4 步租约获取（四报文广播握手）
1. **DHCP DISCOVER (客户机寻找服务器)**：
   - 源 IP: `0.0.0.0`，目的 IP: `255.255.255.255`（受限广播）；
   - 源端口: `UDP 68`，目的端口: `UDP 67`。
2. **DHCPOFFER (服务器提供租约)**：
   - 源 IP: 服务器 IP，目的 IP: `255.255.255.255`（广播）；
   - **核心考点**：服务器在发送 OFFER 之前，必须先在局域网内发出 **ARP 请求**，确保所选 IP 未被其他主机静态占用！
3. **DHCPREQUEST (客户机接受租约)**：
   - 源 IP: `0.0.0.0`，目的 IP: `255.255.255.255`（广播）；
   - **双重意义考点**：以广播形式发送，既告知所选中的服务器接受其提议，又通知其余服务器撤销预留并将 IP 回收到地址池。
4. **DHCPACK (服务器确认租约)**：
   - 源 IP: 服务器 IP，目的 IP: `255.255.255.255`（广播）；
   - 确认分配成功，租约正式生效，进入租用期倒计时。

### 3.2 客户机防冲突机制（第二次 ARP 探测）
- 客户机在收到 `DHCPACK` 后，**必须在局域网内发送免费 ARP (Gratuitous ARP)** 进行冲突检测：
  - **若检测到冲突**：客户机向服务器发送 `DHCPDECLINE` 报文谢绝该 IP，并重新广播 `DHCPDISCOVER`；
  - **若无冲突**：正式绑定启用该 IP 地址。

### 3.3 租期续约生命周期三大时间点
- **0.5 倍租用期 (T1)**：客户机**单播**发送 `DHCPREQUEST` 向原分配服务器申请延长租期：
  - ① 收到 `DHCPACK`：租约倒计时重置，续约成功；
  - ② 收到 `DHCPNACK`：立即停止使用该 IP，重新广播 `DHCPDISCOVER`；
  - ③ 无应答：继续使用，等待 T2。
- **0.875 倍租用期 (T2, 7/8)**：若原服务器未应答，客户机改为**广播**发送 `DHCPREQUEST`，向局域网内任意可用服务器求援；
- **1.0 倍租用期 (到期)**：若仍未收到任何 ACK，**必须立即强制停止使用该 IP**，彻底回到初始状态重新申请。
- **随时提前解约**：客户机可单播发送 `DHCPRELEASE` 提前归还 IP 到地址池。
