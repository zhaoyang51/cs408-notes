# （一）网络层的功能

## 网络层的功能

- 异构网络互连（中继系统：网关/路由器）、路由选择与分组转发、拥塞控制。


---

# （二）路由算法

## 路由算法

### 1. 静态路由与动态路由

- 静态手工配置 vs 动态自适应路由选择协议。

### 2. 距离-向量路由算法（Distance-Vector）

- 仅向相邻路由器交换整个路由表（Bellman-Ford 算法）。缺点：好消息传得快，坏消息传得慢（慢收敛/路由环路计数到无穷）。RIP 协议采用。

### 3. 链路状态路由算法（Link-State）

- 洪泛法向全网所有路由器发送与本路由器相邻的链路状态（Dijkstra 算法计算最短路径树）。OSPF 协议采用。

# （三）IPv4

## IPv4

### 1. IPv4 分组格式

- 首部长度（单位 4B）、总长度（单位 1B）、标识、标志（DF 不分片, MF 更多分片）、片偏移（单位 8B）、生存时间 TTL、协议字段（TCP 6, UDP 17, ICMP 1, OSPF 89）、首部检验和。

### 2. IPv4 地址与子网划分

- **分类 IPv4 地址**：A类（1~126）、B类（128~191）、C类（192~223）、D类（组播 224~239）、E类（保留）。

- **特殊 IP 地址**：网络号全 0（本网络主机）、主机号全 0（网络本身）、主机号全 1（广播地址）、127.0.0.1（环回地址）、私有 IP 地址。

- **子网划分与子网掩码**：两级 IP 变为三级 IP（网络号 + 子网号 + 主机号）。

- **CIDR（无分类编址）与路由聚合（超网）**：斜线记法 a.b.c.d/x，最长前缀匹配原则（Longest Prefix Match）。

### 3. 网络地址转换（NAT）

- 私有内部 IP 与公网 IP 转换，配合 NAPT 端口号映射支持多内网主机共享单一公网 IP。

### 4. 地址解析协议（ARP）

- 通过目标 IP 地址解析出目标 MAC 地址。ARP 请求广播，ARP 响应单播；ARP 高速缓存表。

### 5. 动态主机配置协议（DHCP）

- 应用层协议（基于 UDP 67/68 端口），即插即用自动分配 IP。过程：DHCP Discover（广播） -> Offer -> Request -> ACK。

### 6. 网际控制报文协议（ICMP）

- 封装在 IP 数据报中。分为差错报告报文（终点不可达、源点抑制、时间超过 TTL=0、参数问题、改变路由重定向）与询问报文（Echo 请求与回答/Ping、时间戳请求）。

# （四）IPv6

## IPv6

- **主要特点**：128 位超大地址空间；固定 40 字节基本首部；支持即插即用自动配置；取消首部校验和；不支持中间路由器分片（仅源端分片）。

- **过渡技术**：双协议栈技术（同时运行 IPv4/IPv6）、隧道技术（IPv6 报文封装在 IPv4 数据报中）。


---

# （五）路由协议

## 路由协议

### 1. 自治系统（AS）与层次路由

- 内部网关协议 IGP 与 外部网关协议 EGP。

### 2. 内部网关协议

- **RIP（路由信息协议）**：基于距离-向量，以跳数 Hop（最大 15，16 为不可达）为度量，基于 UDP 520 端口，每 30 秒广播/组播路由表。

- **OSPF（开放最短路径优先）**：基于链路状态与 Dijkstra 算法，直接封装在 IP 数据报中（协议号 89），支持多区域层次划分（骨干区域 Area 0），收敛速度快。

### 3. 外部网关协议

- **BGP-4（边界网关协议）**：基于路径向量协议，基于 TCP 179 端口，在 AS 之间交换可达性路径信息。

# （六）IP 组播与移动 IP

## IP 组播与移动 IP

### 1. IP 组播

- D 类地址（224.0.0.0 ~ 239.255.255.255）；组播 MAC 地址映射（前 24 位 01-00-5E，第 25 位固定为 0，后 23 位映射 IP 后 23 位，存在 32:1 重叠）；IGMP 协议（网际组管理协议）。

### 2. 移动 IP

- 归属代理（本地代理 Home Agent）、外地代理（Foreign Agent）、永久地址（主地址）与转交地址（COA）。移动节点在外部网络注册并三角路由通信。

# （七）网络层设备

## 网络层设备

- **路由器（Router）**：连通不同网络，隔离冲突域与广播域。

- **组成**：路由选择部分（路由选择处理机，维护路由表）与分组转发部分（输入端口、交换结构、输出端口、转发表 Forwarding Table）。
