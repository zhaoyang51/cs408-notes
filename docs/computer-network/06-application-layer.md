# 第6章 应用层 (HTTP / DNS / 邮件)

## 1. 域名系统 (DNS) 解析流程

- **递归查询**：本地域名服务器代为查询。
- **迭代查询**：根域名服务器告诉本地域名服务器下一个应查询的顶级域名服务器 IP。

---

## 2. HTTP 协议核心速查

- **常见状态码**：
  - `200 OK`：成功
  - `301 Moved Permanently`：永久重定向
  - `302 Found`：临时重定向
  - `400 Bad Request`：请求语法错误
  - `403 Forbidden`：服务器拒绝访问
  - `404 Not Found`：资源未找到
  - `500 Internal Server Error`：服务器内部错误
- **持久连接 (HTTP/1.1 默认)**：非流水线方式 vs 流水线方式。
