# 第2章 物理层与通信基础

## 1. 奈奎斯特 vs 香农定理（必考计算）

- **奈氏准则（无噪声信道）**：
  $$\text{极限数据率} = 2W \log_2(V) \quad (\text{b/s})$$
  *(其中 $W$ 为信道带宽 Hz，$V$ 为离散电平数)*

- **香农定理（有噪声信道）**：
  $$\text{极限数据率} = W \log_2(1 + S/N) \quad (\text{b/s})$$
  *(信噪比分贝数 $\text{dB} = 10 \log_{10}(S/N)$)*

## 2. 常见编码技术

- **曼彻斯特编码**：每位周期中心跳变，既表示数据又作为时钟信号（降为 $50\%$ 带宽利用率）。
- **差分曼彻斯特编码**：前半周期有跳变表示 0，无跳变表示 1（抗干扰极佳）。
