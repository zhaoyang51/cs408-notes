# （一）通信基础

## 通信基础

### 1. 基本概念

- 信源、信道、信宿；单工、半双工、全双工通信；基带传输与带通传输。

### 2. 奈奎斯特定理与香农定理

- **奈氏准则（无噪声信道）**：极限数据传输率 = 2 * W * log2(V) (b/s)。（W 为信道带宽 Hz，V 为离散电平数目）。

- **香农定理（有噪声信道）**：极限数据传输率 = W * log2(1 + S/N) (b/s)。（信噪比 dB = 10 * log10(S/N)）。

### 3. 编码与调制

- **数字数据编码为数字信号**：归零码（RZ）、非归零码（NRZ）、曼彻斯特编码（位中心跳变，兼作时钟）、差分曼彻斯特编码（抗干扰好）。

- **数字数据调制为模拟信号**：幅移键控（ASK）、频移键控（FSK）、相移键控（PSK）、正交振幅调制（QAM）。

### 4. 数据交换技术

- 电路交换（独占信道，时延小，利用率低）、报文交换、分组交换（存储转发，利用率高）。

# （二）传输介质

## 传输介质

- **导引型介质**：双绞线（STP/UTP）、同轴电缆、光纤（单模光纤纤芯细适合远距离，多模光纤纤芯粗折射损耗大）。

- **非导引型介质**：无线电波、微波、红外线。


---

# （三）物理层设备

## 物理层设备

- **中继器（Repeater）**：整形放大数字信号（5-4-3 规则）。

- **集线器（Hub）**：多端口中继器，共享带宽，不能隔离冲突域也不能隔离广播域。
