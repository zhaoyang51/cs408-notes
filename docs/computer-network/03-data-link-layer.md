# 第3章 数据链路层与 MAC

## 1. 差错控制：CRC 循环冗余码

- 设生成多项式阶数为 $r$，在待发送数据后补 $r$ 个 0，模 2 除以生成多项式系数，余数即为 **FCS 校验序列**。

---

## 2. 滑动窗口协议对比

| 协议 | 发送窗口 $W_T$ | 接收窗口 $W_R$ | 窗口尺寸限制 (采用 $n$ 位编号) |
|:---|:---:|:---:|:---:|
| **停等协议** | 1 | 1 | $W_T + W_R \le 2^n$ |
| **后退 N 帧 (GBN)** | $> 1$ | 1 (累计确认) | $W_T \le 2^n - 1$ |
| **选择重传 (SR)** | $> 1$ | $> 1$ (单帧确认) | $W_T + W_R \le 2^n \Rightarrow W_T \le 2^{n-1}$ |

---

## 3. CSMA/CD 协议（先听后发，边发边听）

- **争用期 (RTT)**：$2\tau$。
- **最短帧长**：$\text{最短帧长} = 2\tau \times \text{数据传输速率}$（以太网规定为 **64 字节**）。
