# 三、数据链路层

> 本章包含考点小节：8 个

---

# （一）数据链路层的功能

## 数据链路层的功能

- 为网络层提供服务：无确认无连接、有确认无连接、有确认面向连接。

- 封装成帧（帧定界、帧同步、最大传送单元 MTU）、差错控制、流量控制与可靠传输。


---

# （二）组帧

## 组帧

- 字符计数法、字符填充法（字节填充，转义字符 ESC）、零比特填充法（5 个连续 1 填入 1 个 0，HDLC 采用）、违规编码法（曼彻斯特违规电平）。


---

# （三）差错控制

## 差错控制

### 1. 检错编码

- **奇偶校验码**：只能检测出奇数位出错。

- **循环冗余码（CRC）**：模 2 除法求余数作为 FCS 帧检验序列。

### 2. 纠错编码

- **海明码（Hamming Code）**：海明不等式 2^k >= m + k + 1，确定校验位放置在 2^(i-1) 位置。


---

# （四）流量控制与可靠传输机制

## 流量控制与可靠传输机制

### 1. 停止-等待协议（Stop-and-Wait）

- 发送窗口 = 1，接收窗口 = 1。信道利用率 U = T_D / (T_D + RTT + T_A)。

### 2. 后退 N 帧协议（GBN）

- 发送窗口 1 < W_T <= 2^n - 1，接收窗口 W_R = 1。累积确认，超时重发全部未确认帧。

### 3. 选择重传协议（SR）

- 发送窗口 W_T + 接收窗口 W_R <= 2^n，一般 W_T = W_R = 2^(n-1)。逐个确认，只重传出错帧。


---

# （五）介质访问控制（MAC）

## 介质访问控制（MAC）

### 1. 静态划分信道（信道复用）

- FDM（频分复用）、TDM（时分复用）、STDM（统计时分复用）、WDM（波分复用）、CDMA（码分多址，规格化内积判断数据位 1 / 0 / 未发送）。

### 2. 动态分配信道（随机访问介质访问控制）

- **ALOHA 协议**：纯 ALOHA 与时隙 ALOHA。

- **CSMA 协议**：1-坚持 CSMA、非坚持 CSMA、p-坚持 CSMA。

- **CSMA/CD 协议（载波监听多路访问/冲突检测，以太网采用）**：

- 先听后发、边听边发、冲突停发、随机重发。

- 争用期（冲突窗口） 2tau。最小帧长 = 2 * tau * 数据传输率。

- 截断二进制指数退避算法：r = 随机数 0 ~ 2^k - 1 (k = min(重传次数, 10))，退避时间 = r * 2tau。

- **CSMA/CA 协议（冲突避免，无线局域网 802.11 采用）**：

- IFS 帧间间隔（SIFS, PIFS, DIFS）、虚拟载波监听（网络分配向量 NAV）、RTS/CTS 握手预约信道。

# （六）局域网（LAN）

## 局域网（LAN）

### 1. 以太网与 IEEE 802.3

- MAC 地址（48 位，前 24 位 OUI 厂商标识）；以太网 MAC 帧格式（目的 MAC + 源 MAC + 类型 + 数据 + FCS）。

### 2. 无线局域网与 IEEE 802.11

- BSS（基本服务集）、AP（接入点）、ESS（扩展服务集）；802.11 帧的四种地址格式。

### 3. 虚拟局域网（VLAN）

- 划分广播域；IEEE 802.1Q 帧（插入 4 字节 VLAN Tag，包含 12 位 VID，支持 4096 个 VLAN）。


---

# （七）广域网（WAN）

## 广域网（WAN）

- **PPP 协议（点对点协议）**：面向字节，支持全双工，由链路控制协议 LCP、网络控制协议 NCP 组成。采用字节填充（0x7D 转义）或 0 比特插入。只检错不纠错，不可靠传输。


---

# （八）数据链路层设备

## 数据链路层设备

### 1. 网桥（Bridge）与以太网交换机（Switch）

- **原理**：多端口网桥，隔离冲突域，但不能隔离广播域。

- **交换表自学习算法**：源 MAC 学习，目的 MAC 转发（盲目泛洪、单播转发、过滤丢弃）。

- **交换方式**：直通式交换（仅看前 6 字节目的地址即转发）与存储转发式交换（校验 FCS 后转发）。
