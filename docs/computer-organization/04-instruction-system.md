# 四、指令系统

> 本章包含考点小节：6 个

---

# （一）指令系统的基本概念

## 指令系统的基本概念

- 指令集体系结构（ISA）是软硬件接口边界，定义机器指令格式、寻址方式及寄存器组织。


---

# （二）指令格式

## 指令格式

- **操作码字段**：定长操作码与扩展操作码（短操作码为长操作码预留逃逸码）。

- **地址码字段**：零地址指令、一地址指令、二地址指令、三地址指令格式。


---

# （三）寻址方式

## 寻址方式

### 1. 指令寻址

- **顺序寻址**：(PC) + 1 -> PC。

- **跳跃寻址**：转移指令修改 PC。

### 2. 数据寻址（10 种核心寻址方式）

- 立即寻址（操作数在指令中）、直接寻址（EA = A）、间接寻址（EA = (A)）、寄存器寻址（EA = R_i）、寄存器间接寻址（EA = (R_i)）。

- **偏移寻址**：

- 相对寻址：EA = (PC) + A（常用于转移指令）。

- 基址寻址：EA = (BR) + A（面向操作系统，利于多道程序浮动）。

- 变址寻址：EA = (IX) + A（面向用户，利于数组循环遍历）。

- **堆栈寻址**：利用堆栈指针 SP 存取。


---

# （四）数据的对齐和大/小端存放方式

## 数据的对齐和大/小端存放方式

- **大端模式（Big-Endian）**：最高有效字节（MSB）存储在最低内存地址。

- **小端模式（Little-Endian）**：最低有效字节（LSB）存储在最低内存地址。

- **边界对齐存储**：数据地址必须是该数据类型大小的整数倍，避免跨周期双重访存。


---

# （五）CISC 和RISC 的基本概念

## CISC 和RISC 的基本概念

- **CISC（复杂指令集）**：指令丰富多样，长度可变，寻址方式多，采用微程序控制器，典型如 x86。

- **RISC（精简指令集）**：指令少而简单，长度固定，多通用寄存器，仅 LOAD/STORE 访存，硬布线控制，便于流水线实现，典型如 ARM/RISC-V。

# （六）高级语言程序与机器代码之间的对应

## 高级语言程序与机器代码之间的对应

- 编译、汇编、链接全过程；条件选择分支、循环结构的汇编代码对应；函数调用与过程调用栈（CALL/RET 指令、参数传递、帧指针 EBP/RBP、局部变量分配）。
