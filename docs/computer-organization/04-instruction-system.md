# 第4章 指令系统与寻址方式

## 1. 常见寻址方式速查表

| 寻址方式 | 有效地址 (EA) 计算 | 访存次数 (取指后) | 特点与应用 |
|:---|:---|:---:|:---|
| **立即寻址** | $A$ 即为操作数 | 0 | 常量赋值 |
| **直接寻址** | $EA = A$ | 1 | 简单直接 |
| **间接寻址** | $EA = (A)$ | 2 | 扩大寻址范围 |
| **寄存器寻址** | $EA = R_i$ | 0 | 最快 |
| **基址寻址** | $EA = (BR) + A$ | 1 | 多道程序定位，面向操作系统 |
| **变址寻址** | $EA = (IX) + A$ | 1 | 数组遍历，面向程序员 |
| **相对寻址** | $EA = (PC) + A$ | 1 | 条件跳转指令 |

## 2. CISC vs RISC

| 指标 | CISC (复杂指令集) | RISC (精简指令集) |
|:---|:---|:---|
| 指令条数 | 庞大繁多 | 极少、精简定长 |
| 控制器实现 | **微程序控制器** 为主 | **硬布线控制器** 为主 |
| 流水线支持 | 较难 | **原生支持良好** |
