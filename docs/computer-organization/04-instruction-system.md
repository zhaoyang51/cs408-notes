## 1. 8 大常见指令寻址方式全景速查

| 寻址方式 | 有效地址 (EA) 推导公式 | 访存次数 (取指后) | 典型应用与特点 |
|:---|:---|:---:|:---|
| **立即寻址** | 操作数直接在指令中 | **0 次** | 存取常数，最快 |
| **直接寻址** | $EA = A$ | **1 次** | 寻址范围有限 |
| **间接寻址** | $EA = (A)$ | **2 次以上** | 扩大寻址范围，灵活 |
| **寄存器寻址** | $EA = R_i$ | **0 次** | 寄存器操作，极快 |
| **寄存器间接** | $EA = (R_i)$ | **1 次** | 适合循环与链表操作 |
| **基址寻址** | $EA = (BR) + A$ | **1 次** | 多道程序动态重定位（OS 面向） |
| **变址寻址** | $EA = (IX) + A$ | **1 次** | 数组遍历（程序员面向） |
| **相对寻址** | $EA = (PC) + A$ | **1 次** | 条件跳转指令（相对 PC 转移） |

## 2. CISC vs RISC 指令系统对比

| 特性 | CISC (复杂指令集，如 x86) | RISC (精简指令集，如 ARM/MIPS) |
|:---|:---|:---|
| **指令系统** | 庞杂，指令长度不固定 | 精炼定长，格式规范 |
| **访存指令** | 多数指令均可直接访存 | **仅 Load / Store 指令可访存** |
| **控制器实现** | 绝大多数采用 **微程序控制器** | 绝大多数采用 **硬布线控制器** |
| **流水线效率** | 流水线调度困难 | **原生天然适配高效流水线** |
