# （一）数制与编码

## 数制与编码

### 1. 进位计数制及其相互转换

- 二进制、八进制、十进制、十六进制转换；真值与机器数。

### 2. 定点数的编码表示

- **原码**：符号位 + 绝对值数值位。0 有两种表示（+0 和 -0）。

- **反码**：正数同原码，负数数值位取反。

- **补码**：正数同原码，负数数值位取反加 1。0 的表示唯一。模运算原理，最小负数表示（-2^n）。

- **移码**：补码符号位取反（常用于浮点数阶码）。

### 3. 整数与小数表示范围

- n+1 位定点整数补码范围：-2^n ~ 2^n - 1。

# （二）运算方法和运算电路

## 运算方法和运算电路

### 1. 基本运算部件

- **一位全加器（FA）**：本位和 S = A ^ B ^ C_in，进位 C_out = A*B + (A^B)*C_in。

- **行波进位加法器**：串行进位链，延迟与位数成正比。

- **先行进位加法器（CLA）**：快速进位产生 G_i = A_i * B_i 与传递 P_i = A_i ^ B_i，并行生成进位。

- **算术逻辑单元（ALU）**：组合逻辑电路，完成算术与逻辑运算。

### 2. 加/减运算

- **补码加减法运算器**：[A-B]_补 = [A]_补 + [-B]_补。

- **标志生成电路**：

- OF（溢出标志）：OF = C_out ^ C_sign（符号位进位 ^ 最高有效位进位）。

- SF（符号标志）：SF = 最高有效位结果。

- ZF（零标志）：ZF = 结果全为 0 时置 1。

- CF（进位/借位标志）：CF = Sub ^ C_out（无符号数溢出）。

### 3. 乘/除运算

- **原码一位乘法**：符号与数值分开，数值位由累加和右移完成。

- **补码一位乘法（Booth 算法）**：根据 y_i - y_{i+1} 决定 +[x]_补、-[-x]_补 或 不操作，算术右移。

- **除法**：原码恢复余数法与加减交替法（不恢复余数法）。

# （四）浮点数的表示和运算

## 浮点数的表示和运算

### 1. IEEE 754 标准

- **单精度（float 32位）**：1位符号S + 8位阶码E（偏置值 127） + 23位尾数M（隐含最高位 1.M）。真值 = (-1)^S * 2^(E-127) * (1.M)。

- **双精度（double 64位）**：1位符号S + 11位阶码E（偏置值 1023） + 52位尾数M。

- **特殊值**：

- E 全 0，M 全 0：表示 +/- 0。

- E 全 1，M 全 0：表示 +/- 无穷大（Inf）。

- E 全 1，M != 0：表示非数值（NaN）。

- 非规格化数（E 全 0，M != 0）：真值 = (-1)^S * 2^(-126) * (0.M)。

### 2. 浮点数加/减运算

- ① **对阶**：求阶差，小阶向大阶看齐，小阶尾数右移（阶差位）。

- ② **尾数求和**：尾数按补码加减。

- ③ **规格化**：左规（尾数左移，阶码减1）与右规（尾数右移，阶码加1，最高位产生溢出时）。

- ④ **舍入**：0舍1入法、恒置1法。

- ⑤ **溢出判断**：阶码上溢（抛出异常）与阶码下溢（当作0处理）。
