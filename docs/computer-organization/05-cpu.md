# 五、中央处理器（CPU）

> 本章包含考点小节：7 个

# （一）CPU的功能和基本结构

## CPU的功能和基本结构

- **功能**：指令控制、操作控制、时间控制、数据加工、中断处理。

- **组成**：运算器（ALU、通用寄存器组、暂存器）、控制器（PC、IR、指令译码器、MAR、MDR、PSW、时序系统）。


---

# （二）指令执行过程

## 指令执行过程

- 指令周期 = 取指周期 + 间址周期 + 执行周期 + 中断周期。各周期数据流通路与微操作控制序列。


---

# （三）数据通路的功能和基本结构

## 数据通路的功能和基本结构

- 专用数据通路（多路选择器 MUX 互连）与总线式数据通路（单总线、多总线）中数据在寄存器与 ALU 之间的流动控制信号。

# （四）控制器的功能和工作原理

## 控制器的功能和工作原理

### 1. 硬布线控制器（组合逻辑控制器）

- 由逻辑门和触发器构成的组合逻辑网络，速度快，但设计复杂、不易扩充，广泛用于 RISC 处理器。

### 2. 微程序控制器

- **核心概念**：微命令、微操作、微指令、微程序、控制存储器（CM）。

- **微指令编码**：字段直接编码法（互斥微命令同段，相容微命令分段，保留 1 个不发命令状态）。

- **微地址形成方式**：下地址字段直接给出、根据操作码映射（断路分支）。

# （五）异常和中断机制

## 异常和中断机制

### 1. 异常（内中断）

- 由 CPU 内部事件引起：故障（Fault，如缺页）、陷阱（Trap，如系统调用）、终止（Abort，如硬件故障）。

### 2. 中断（外中断）

- 由 CPU 外部 I/O 设备引起：可屏蔽中断（INTR）与不可屏蔽中断（NMI）。

### 3. 中断处理过程

- 关中断 -> 保存断点与 PSW -> 寻找中断服务程序入口（中断向量表） -> 保护现场 -> 执行中断服务 -> 恢复现场 -> 开中断 -> 中断返回。

# （六）指令流水线

## 指令流水线

### 1. 经典五段流水线

- IF（取指）、ID（译码/读寄存器）、EX（执行/有效地址计算）、MEM（访存）、WB（写回寄存器）。

### 2. 流水线性能指标

- 吞吐率 TP = n / Tk，加速比 S = T_seq / T_pipe，效率 E = 实际有效面积 / 总时空区。

### 3. 三大流水线冒险（冲突）及解决方案

- **结构冒险（资源冲突）**：多条指令争用同一硬件资源。解决：指令 Cache 与数据 Cache 分离。

- **数据冒险（RAW, WAR, WAW）**：下一指令需要上一指令尚未写回的数据。解决：数据转发/旁路技术（Forwarding）、插入气泡（NOP）、编译器调度。

- **控制冒险（分支冲突）**：转移指令改变 PC。解决：静态/动态分支预测、延迟槽（Branch Delay Slot）。

### 4. 高级流水线技术

- 超标量（多发射）、超流水线、动态流水线（乱序执行与保留站）。

# （七）多处理器的基本概念

## 多处理器的基本概念

- **分类**：SISD、SIMD（向量处理器）、MISD、MIMD（多计算机与多处理器系统）。

- **硬件多线程**：细粒度多线程、粗粒度多线程、同时多线程（SMT/超线程）。

- **多核处理器与多处理器**：CMP（单芯片多核）、SMP（对称多处理，UMA 统一内存访问与 NUMA 非统一内存访问）。
