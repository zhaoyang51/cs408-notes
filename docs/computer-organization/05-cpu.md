# 第5章 CPU、数据通路与控制器

## 1. 指令周期与微操作流程

1. **取指周期**：`PC -> MAR -> 主存 -> MDR -> IR; (PC)+1 -> PC`
2. **间址周期**：`Ad(IR) -> MAR -> 主存 -> MDR -> EA`
3. **执行周期**：根据操作码进行 ALU 运算与结果写回
4. **中断周期**：保存断点 `SP-1 -> SP, (PC) -> 主存, 中断向量 -> PC`

---

## 2. 硬布线 vs 微程序控制器

- **硬布线（组合逻辑）**：门电路硬连线，**速度快**，修改难（RISC）。
- **微程序（存储逻辑）**：指令拆解为微命令，存放在 **控制存储器 (CM)** 中，**规整易扩充**，速度较慢（CISC）。

---

## 3. 指令流水线冒险 (Hazard)

| 冒险类型 | 原因 | 解决办法 |
|:---|:---|:---|
| **结构冒险** (资源冲突) | 多个指令同时争用同一硬件（如单一访存端口） | 插入气泡、数据与指令 Cache 分离 |
| **数据冒险** (RAW/WAR/WAW) | 后续指令需要前面指令未写回的数据 | **数据旁路转发 (Forwarding)**、编译器重排 |
| **控制冒险** (分支跳转) | 分支指令改变 PC | 分支预测、延迟槽技术 |
