## 1. 指令周期 4 个阶段微操作流程

1. **取指周期 (Fetch)**：`PC -> MAR; 主存 -> MDR; MDR -> IR; (PC)+1 -> PC`
2. **间址周期 (Indirect)**：`Ad(IR) -> MAR; 主存 -> MDR; MDR -> EA`
3. **执行周期 (Execute)**：ALU 逻辑运算与状态标志寄存器 (PSW) 更新
4. **中断周期 (Interrupt)**：`SP-1 -> SP; (PC) -> 主存; 中断向量 -> PC; 关中断`

---

## 2. 硬布线 vs 微程序控制器

- **硬布线（组合逻辑门）**：速度极快，设计修改极其困难（RISC 标配）。
- **微程序（存储逻辑）**：将指令细化为微命令保存在 **控制存储器 (CM)** 中，易于扩充修改（CISC 标配）。

---

## 3. 指令流水线 3 大冒险与解决方案

| 冒险类型 | 产生原因 | 应对解决策略 |
|:---|:---|:---|
| **结构冒险 (Resource)** | 多个指令在同一周期争用同一硬件资源 | 插入硬件气泡 (Stall)、指令与数据 Cache 分离 |
| **数据冒险 (RAW/WAR/WAW)** | 后续指令依赖前面尚未写回的数据 | **数据旁路转发 (Forwarding)**、编译器指令重排 |
| **控制冒险 (Branch)** | 分支跳转改变了 PC 导致流水线断流 | 分支预测 (Branch Prediction)、延迟槽技术 |
