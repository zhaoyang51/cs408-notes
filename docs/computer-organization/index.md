### ⚡ 2. 高频重点考点（总考频 9 ~ 12 次）

- **计算机性能指标（12 次：选择 11，简答 1）**：CPI、MIPS、主频、时钟周期与 CPU 执行时间综合计算。
- **总线的组成及性能指标（12 次：选择 12，简答 0）**：总线宽度、总线带宽计算、同步/异步定时与突发传输。
- **计算机系统层次结构（11 次：选择 11，简答 0）**：ISA 指令集架构概念、软硬件逻辑等价性与多层抽象模型。
- **CPU 的功能和基本结构（11 次：选择 6，简答 5）**：通用寄存器、PC、IR、MAR、MDR 的功能与内部连接。
- **硬布线 / 微程序控制器（11 次：选择 7，简答 4）**：水平/垂直微指令格式、微地址下址形成方式及控制单元设计。
- **Cache 的基本工作原理（10 次：选择 6，简答 4）**：命中率、缺失率、平均访存时间与局部性原理。
- **半导体随机存取存储器（9 次：选择 8，简答 1）**：SRAM 与 DRAM 芯片特性对比、DRAM 刷新机制、字/位芯片扩展。
- **DMA 方式（9 次：选择 5，简答 4）**：DMA 传送三阶段（预处理/数据传输/后处理）、与中断方式的区别。
- **I/O 接口 (I/O 控制器)（9 次：选择 7，简答 2）**：统一编址（存储器映射）与独立编址对比、控制/状态/数据端口访问。
