# 三、存储器层次结构

> 本章包含考点小节：7 个

---

# （一）存储器的分类

## 存储器的分类

- **按存储介质**：半导体存储器、磁表面存储器、光盘存储器。

- **按存取方式**：随机存取存储器（RAM）、只读存储器（ROM）、顺序存取存储器（SAM）、直接存取存储器（DAM）。

- **按信息的可保存性**：易失性存储器（RAM）与非易失性存储器（ROM、Flash、磁盘）。


---

# （二）层次化存储器的基本结构

## 层次化存储器的基本结构

- **存储体系层次**：寄存器 -> Cache -> 主存 -> 辅助存储器（外存）。

- **局部性原理**：时间局部性（最近访问的信息不久还会被访问）与空间局部性（相邻地址的信息不久会被访问）。


---

# （三）半导体随机存取存储器

## 半导体随机存取存储器

- **SRAM（静态随机存储器）**：双稳态触发器存储信息，速度快，集成度低，功耗大，常用于 Cache。

- **DRAM（动态随机存储器）**：栅极电容电荷存储信息，集成度高，需定期刷新（集中刷新、分散刷新、异步刷新），常用于主存。

- **Flash 存储器（闪存）**：非易失，电可擦除，以块为擦除单位，广泛用于 SSD 与 BIOS ROM。


---

# （四）主存储器

## 主存储器

- **DRAM 芯片与内存条**：地址引脚复用技术（行地址和列地址分两次输入）。

- **多模块存储器**：

- **单体多字存储器**：一次读写多个连续字。

- **多体交叉存储器**：高位交叉编址（顺序方式）与低位交叉编址（流水方式）。低位交叉 m 体存储器连续存取 m 个字耗时 T + (m-1)tau。

- **主存与 CPU 的连接**：位扩展、字扩展、字位同时扩展，地址译码器片选信号设计。


---

# （五）外部存储器

## 外部存储器

### 1. 机械硬盘（HDD）

- 存取时间 = 寻道时间 + 旋转延迟时间（半圈时间） + 传输时间。磁盘容量与数据传输率计算。

### 2. 固态硬盘（SSD）

- 基于闪存 Flash，读写以页（Page）为单位，擦除以块（Block）为单位；存在写放大与磨损均衡（动态磨损均衡与静态磨损均衡）。


---

# （六）高速缓冲存储器（Cache）

## 高速缓冲存储器（Cache）

### 1. Cache 基本工作原理

- 命中率 H，平均访问时间 T_a = H * t_c + (1-H) * t_m。

### 2. Cache 和主存的映射方式

- **直接映射**：主存块号 % Cache 总行数。地址结构：Tag + Cache 行号 + 块内地址。

- **全相联映射**：可装入 Cache 任意一行。地址结构：Tag + 块内地址。

- **组相联映射**：主存块号 % Cache 组数。地址结构：Tag + 组号 + 块内地址。

### 3. Cache 中主存块的替换算法

- RAND（随机算法）、FIFO（先进先出）、LRU（近期最少使用，命中率高）、LFU（最不经常使用）。

### 4. Cache 写策略

- **写命中**：全写法（Write-Through，同时写 Cache 和主存）与写回法（Write-Back，只写 Cache，换出时写回主存，设脏位 Dirty Bit）。

- **写未命中**：写分配法（Write-Allocate，装入 Cache 再写）与非写分配法（Not-Write-Allocate，直接写主存）。


---

# （七）虚拟存储器

## 虚拟存储器

### 1. 页式虚拟存储器

- 页表、虚页号到物理页号的地址变换；快表（TLB）并行查询；TLB 缺失、Cache 缺失与缺页中断的联合处理流程。

### 2. 段式与段页式虚拟存储器

- 段式虚存（按逻辑模块分段）、段页式虚存（先分段再分页，逻辑地址包含段号+段内页号+页内偏移量，需三次访存）。
