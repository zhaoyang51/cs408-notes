# 第3章 存储器层次结构 (Cache / 主存)

## 1. 主存与 Cache 映射方式

主存地址划分对比表：

| 映射方式 | 主存地址划分 | 特点 |
|:---|:---|:---|
| **直接映射** | `[ 主存字块标记 | Cache 行号 | 块内地址 ]` | 映射固定，易冲突 |
| **全相联映射**| `[ 主存字块标记 | 块内地址 ]` | 任意位置存放，查表慢 |
| **组相联映射**| `[ 主存字块标记 | 组号 (Set) | 块内地址 ]` | 兼顾速度与冲突率（408 最常考） |

::: tip 💡 Cache 容量计算公式
Cache 总位数 = 行数 $\times$ (数据位数 + 标记 Tag 位数 + 有效位 1 + 脏位 1 + 替换算法 LRU 位)
:::

## 2. 虚拟存储器与页表

- **虚地址到物理地址转换**：
  $$\text{虚拟地址} = [\text{虚页号 VPN} \mid \text{页内偏移量 PO}]$$
  $$\text{物理地址} = [\text{物理页框号 PPN} \mid \text{页内偏移量 PO}]$$
- **访存判定次序**：TLB（快表）命中 $\rightarrow$ 页表（慢表）命中 $\rightarrow$ 缺页中断（访外存）。
