# （一）计算机系统层次结构

## 计算机系统层次结构

### 1. 计算机系统的基本组成

- **硬件系统**：运算器、控制器、存储器、输入设备、输出设备。

- **软件系统**：系统软件（操作系统、DBMS、语言处理程序等）与应用软件。

### 2. 计算机硬件的基本组成

- **冯·诺依曼机特点**：

- 指令和数据以同等地位存放在存储器中，并可按地址寻访。

- 指令和数据均用二进制代码表示。

- 指令由操作码和地址码组成。

- 指令在存储器中按顺序存放。

- 机器以运算器为中心（现代计算机以存储器为中心）。

### 3. 计算机软件和硬件的关系

- 逻辑功能的等价性（某些功能既可用硬件实现，也可用软件实现）。

### 4. 计算机系统的工作原理

- **“存储程序”工作方式**：程序和数据预先存放在主存储器中，启动后自动高速逐条执行。

- **高级语言到机器语言的转换**：编译方式（生成目标代码）、解释方式（逐句翻译并执行）、汇编方式。

- **指令执行过程**：取指令（PC -> MAR -> 主存 -> MDR -> IR，(PC)+1） -> 指令译码 -> 执行指令 -> 访存/写回。

# （二）计算机性能指标

## 计算机性能指标

### 1. 基本指标

- **吞吐量（Throughput）**：系统在单位时间内处理请求的数量。

- **响应时间（Response Time）**：用户发送请求到系统做出响应的时间。

### 2. CPU 性能指标

- **主频（CPU Clock Rate）**：CPU 时钟频率 f = 1 / CPU 时钟周期。

- **CPI（Cycles Per Instruction）**：执行一条指令所需的平均时钟周期数。

- **CPU 执行时间**：CPU Time = (指令条数 * CPI) / 主频 = 指令条数 * CPI * 时钟周期。

### 3. 运算速度指标

- **MIPS（Million Instructions Per Second）**：每秒百万条指令数 = 指令条数 / (执行时间 * 10^6) = 主频 / (CPI * 10^6)。

- **FLOPS（Floating-point Operations Per Second）**：每秒浮点运算次数（MFLOPS, GFLOPS, TFLOPS, PFLOPS, EFLOPS, ZFLOPS）。
