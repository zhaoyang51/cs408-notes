# 六、总线和输入输出系统

> 本章包含考点小节：3 个

---

# （一）总线

## 总线

### 1. 总线分类与结构

- 内部总线、系统总线（数据总线、地址总线、控制总线）、通信总线。单总线、双总线、三总线结构。

### 2. 总线性能指标

- 总线宽度（数据线根数）、总线时钟周期与频率、总线带宽（B/s = 频率 * 宽度 / 8）。

### 3. 总线事务与定时

- 同步定时（统一时钟脉冲）与异步定时（不互锁、半互锁、全互锁握手信号）。

# （二）I/O 接口（I/O 控制器）

## I/O 接口（I/O 控制器）

- **功能**：主机与外设通信控制、寻址、数据缓冲、状态监测。

- **内部寄存器**：数据寄存器、状态寄存器、控制寄存器。

- **端口编址方式**：统一编址（内存映射 I/O，占用内存空间，无需专用 I/O 指令）与独立编址（专用 I/O 指令如 IN/OUT，地址空间独立）。


---

# （三）I/O 方式

## I/O 方式

### 1. 程序查询方式

- CPU 踏步轮询等待 I/O 就绪，CPU 利用率极低。

### 2. 程序中断方式

- I/O 准备好后向 CPU 发中断请求，CPU 暂停当前程序进行服务。

- **多重中断与中断屏蔽字**：多重中断允许高优先级中断打断低优先级中断；通过设置屏蔽字动态改变优先级。

### 3. DMA 方式（直接内存存取）

- **特点**：完全由硬件实现主存与外设之间的高速成块数据交换，无需 CPU 中介。

- **DMA 控制器组成**：主存地址寄存器（MAR）、传送长度计数器（WC）、数据缓冲寄存器（DBR）、控制状态寄存器（CSR）。

- **DMA 传送过程**：预处理（CPU 初始化 DMA 参数） -> 数据传送（DMA 控制器接管总线，周期挪用/窃取） -> 后处理（传送结束发中断通知 CPU）。
