# 第5章 图

## 1. 图的基本性质

- **握手定理**：所有顶点度数之和 $= 2 \times$ 边数 $E$。
- **极大连通子图**（连通分量）；**极小连通子图**（连通图的生成树，$n$ 个顶点必有 $n-1$ 条边）。

---

## 2. 图的经典算法全景对比表

| 算法 | 解决问题 | 时间复杂度 (邻接矩阵) | 时间复杂度 (邻接表) | 适用场景 / 限制 |
|:---|:---|:---:|:---:|:---|
| **BFS / DFS** | 图遍历 | $O(V^2)$ | $O(V + E)$ | 连通性判断 |
| **Prim** | 最小生成树 | $O(V^2)$ | $O(V^2)$ | **稠密图**（点多边多） |
| **Kruskal** | 最小生成树 | $O(E \log E)$ | $O(E \log E)$ | **稀疏图**（边少） |
| **Dijkstra** | 单源最短路径 | $O(V^2)$ | $O(V^2)$ / $O(E \log V)$ | **不可有负权边** |
| **Floyd** | 各顶点间最短路 | $O(V^3)$ | $O(V^3)$ | 允许负权边，不能有负权回路 |
| **拓扑排序 (AOV)** | 有向无环图排序 | $O(V^2)$ | $O(V + E)$ | 判断是否有环、选课依赖 |
| **关键路径 (AOE)** | 最早/最迟发生时间 | $O(V + E)$ | $O(V + E)$ | 最长路径决定工程总工期 |
