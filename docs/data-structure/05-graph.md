## 1. 图的存储结构对比

| 存储结构 | 空间复杂度 | 找顶点的邻接点 | 适用场景 |
|:---|:---:|:---|:---|
| **邻接矩阵** | $O(V^2)$ | 遍历整行 $O(V)$ | **稠密图**、有向/无向图均可 |
| **邻接表** | $O(V + E)$ / $O(V + 2E)$ | 遍历单链表（出边） | **稀疏图** |

## 2. 7 大经典图论算法全景速查表

| 算法名称 | 解决问题 | 时间复杂度 (邻接矩阵) | 时间复杂度 (邻接表) | 适用约束 / 核心策略 |
|:---|:---|:---:|:---:|:---|
| **BFS** | 广度优先遍历 / 无权最短路 | $O(V^2)$ | $O(V+E)$ | 借助辅助队列 |
| **DFS** | 深度优先遍历 | $O(V^2)$ | $O(V+E)$ | 递归 / 辅助栈 |
| **Prim** | 最小生成树 (MST) | $O(V^2)$ | $O(V^2)$ | **稠密图优先**（基于顶点扩展） |
| **Kruskal**| 最小生成树 (MST) | $O(E \log E)$ | $O(E \log E)$ | **稀疏图优先**（按边权递增，并查集判环） |
| **Dijkstra**| 单源最短路径 | $O(V^2)$ | $O(V^2)$ / $O(E \log V)$ | **严禁含有负权边** |
| **Floyd** | 所有顶点对间最短路 | $O(V^3)$ | $O(V^3)$ | 动态规划，允许负权边，禁止负权回路 |
| **拓扑排序**| 有向无环图 (DAG) 判定与排序 | $O(V^2)$ | $O(V+E)$ | 统计入度，入度为 0 进栈/队列 |
| **关键路径**| 工程总工期与关键活动 | $O(V+E)$ | $O(V+E)$ | 最早发生时间 $ve(k) = $ 最迟发生时间 $vl(k)$ |
