# （一）图的基本概念

## 图的基本概念

### 1. 图的定义与分类

- 有向图与无向图、简单图、完全图（无向完全图边数 n(n-1)/2，有向完全图弧数 n(n-1)）。

- 连通图与连通分量（极大连通子图）、强连通图与强连通分量。

- 顶点的度、入度、出度（无向图总度数 = 2 * 边数；有向图总入度 = 总出度 = 弧数）。

- 生成树（包含全部 n 个顶点的极小连通子图，恰好 n-1 条边）。


---

# （二）图的存储及基本操作

## 图的存储及基本操作

### 1. 邻接矩阵

- 二维数组表示。空间复杂度 O(|V|^2)，适合稠密图。无向图邻接矩阵对称。

### 2. 邻接表

- 顶点表 + 边表（单链表）。空间复杂度 O(|V| + |E|)，适合稀疏图。

### 3. 邻接多重表、十字链表

- 十字链表是有向图的链式存储；邻接多重表是无向图的链式存储。


---

# （三）图的遍历

## 图的遍历

### 1. 深度优先搜索（DFS）

- 类似树的先序遍历，借助递归或栈实现。空间复杂度 O(|V|)，邻接矩阵时间 O(|V|^2)，邻接表时间 O(|V| + |E|)。

### 2. 广度优先搜索（BFS）

- 类似树的层次遍历，借助队列实现。可用于求解无权图的单源最短路径。


---

# （四）图的基本应用

## 图的基本应用

### 1. 最小（代价）生成树（MST）

- **Prim 算法**：从顶点出发逐步加点，适合稠密图，时间复杂度 O(|V|^2)。

- **Kruskal 算法**：从边出发逐步加边（并查集防成环），适合稀疏图，时间复杂度 O(|E| log |E|)。

### 2. 最短路径

- **Dijkstra 算法**：单源最短路径（不能处理负权边），贪心策略，时间复杂度 O(|V|^2)。

- **Floyd 算法**：各顶点间最短路径（动态规划），允许负权边但不能有负权环，时间复杂度 O(|V|^3)。

### 3. 拓扑排序

- AOV 网（顶点表示活动），每次选择入度为 0 的顶点输出并删除其出边。可用于检测有向图中是否存在环。

### 4. 关键路径

- AOE 网（边表示活动，权值表示持续时间）。

- 事件最早发生时间 ve(k)、最迟发生时间 vl(k)；活动最早开始时间 e(i)、最迟开始时间 l(i)。

- 时间余量 d(i) = l(i) - e(i) == 0 的活动为关键活动，关键活动组成的路径为关键路径（决定工程最短总工期）。
