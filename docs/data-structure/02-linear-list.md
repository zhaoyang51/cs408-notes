# 第2章 线性表

## 1. 顺序表 vs 链表核心对比

| 操作 | 顺序表 (Array) | 单链表 (LinkedList) |
|:---|:---:|:---:|
| **按位查找** | $O(1)$（随机存取） | $O(n)$（顺序存取） |
| **按值查找** | $O(n)$（无序）/ $O(\log n)$（有序） | $O(n)$ |
| **插入 / 删除** | $O(n)$（需移动元素） | $O(1)$（已知指针位置） |
| **存储密度** | 高（$= 1$） | 较低（需存指针域） |

---

## 2. 各种链表特性速查

- **单链表**：找前驱困难（$O(n)$）；判空：`head->next == NULL`（带头结点）。
- **双链表**：插入删除 $O(1)$ 操作前后双向指针。
- **循环单链表**：表尾结点的 `next` 指向 `head`；判空：`head->next == head`。
- **静态链表**：借助数组描述链式结构，指针为数组下标 `next`。

---

## 3. 经典算法技巧（大题高频）

1. **双指针 / 快慢指针**：
   - 寻找链表倒数第 $k$ 个结点（快指针先走 $k$ 步）。
   - 判断链表是否有环（快指针每次走 2 步，慢指针走 1 步）。
   - 寻找链表中间结点。
2. **头插法 vs 尾插法**：
   - 头插法：读入顺序与链表顺序**相反**（常用于链表逆置）。
   - 尾插法：读入顺序与链表顺序**相同**。
