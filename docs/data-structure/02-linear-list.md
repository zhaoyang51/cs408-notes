## 1. 顺序表 vs 链表全景对比

| 操作特性 | 顺序表 (Array) | 单链表 (LinkedList) | 双向链表 (Doubly Linked) |
|:---|:---:|:---:|:---:|
| **按位查找** $GetElem(i)$ | **$O(1)$**（随机存取） | $O(n)$（顺序存取） | $O(n)$ |
| **按值查找** $LocateElem(e)$ | $O(n)$ / 有序 $O(\log n)$ | $O(n)$ | $O(n)$ |
| **已知指针插入/删除** | $O(n)$（需移动后续元素） | **$O(1)$** | **$O(1)$** |
| **头/尾插入删除** | 头部 $O(n)$，尾部 $O(1)$ | 带尾指针 $O(1)$ | 带尾指针 $O(1)$ |
| **存储密度** | **$= 1$**（最高） | $< 1$（包含指针域） | 更低（包含双向指针） |

## 2. 常用链表操作与判空条件

| 链表类型 | 判空条件（带头结点） | 核心优势 | 缺点 |
|:---|:---|:---|:---|
| **单链表** | `head->next == NULL` | 结构简单，动态扩容 | 寻找前驱结点需 $O(n)$ |
| **循环单链表** | `head->next == head` | 从任意结点出发均可遍历全表 | 需警惕死循环 |
| **双向链表** | `head->next == NULL` | 插入删除前后结点均为 $O(1)$ | 空间开销多一个 `prior` |
| **静态链表** | `next == -1` | 借助数组下标，无需系统指针 | 容量固定不可扩充 |

## 3. 算法大题秒杀技巧

::: info 💡 408 链表解题 3 大法宝
<ul>
    <li><strong>快慢指针法</strong>：快指针每次走 2 步，慢指针走 1 步，用于找中点、找倒数第 $k$ 个结点、判环。</li>
    <li><strong>头插法原地逆置</strong>：遍历链表，逐个结点断开并头插至新头部，时间 $O(n)$，空间 $O(1)$。</li>
    <li><strong>归并双指针</strong>：用于合并两个有序单链表或寻找两个集合交集。</li>
  </ul>
:::



::: details 🎯 ⭐️ 408 经典真题自测 如何用时间 $O(n)$、空间 $O(1)$ 查找单链表中倒数第 $k$ 个结点？

**【算法步骤】**：

    
      - 定义两个指针 `p, q`，初始均指向头结点的下一个结点。
      - 指针 `p` 先向前走 $k$ 步。若中途 `p == NULL`，说明链表长度 $< k$，查找失败。
      - 随后 `p, q` 同时向前同步移动，直到 `p == NULL`。
      - 此时 `q` 所指结点即为倒数第 $k$ 个结点。

:::
