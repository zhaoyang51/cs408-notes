# （一）线性表的基本概念

## 线性表的基本概念

### 1. 线性表的定义

- 具有相同数据类型的 n (n >= 0) 个数据元素的有限序列。n 为表长，n=0 时为空表。

### 2. 线性表的基本特征

- 元素个数有限；逻辑上元素有先后次序；每个元素占用相同大小的存储空间；除第一个元素外每个元素有且仅有一个直接前驱，除最后一个元素外每个元素有且仅有一个直接后继。

# （二）线性表的实现

## 线性表的实现

### 1. 顺序存储（顺序表 Sequence List）

- **特点**：随机存取（按序号访问元素时间复杂度为 O(1)）；存储密度高；插入和删除需要移动大量元素。

- **插入操作**：在第 i (1 <= i <= n+1) 个位置插入，平均移动元素次数为 n/2，时间复杂度 O(n)。

- **删除操作**：删除第 i (1 <= i <= n) 个位置元素，平均移动元素次数为 (n-1)/2，时间复杂度 O(n)。

### 2. 链式存储（单链表、双链表、循环链表、静态链表）

- **单链表**：数据域 data + 指针域 next。头结点使得第 1 个位置的操作与其余位置一致，且空表与非空表处理统一。

- **双链表**：包含 prior 指针与 next 指针，便于双向查找与 O(1) 删除当前结点。

- **循环链表**：

- 循环单链表：表中最后一个结点的指针指向头结点。若设尾指针 rear，则在表头和表尾插入/删除时间均为 O(1)。

- 循环双链表：头结点的 prior 指向尾结点，尾结点的 next 指向头结点。

- **静态链表**：借助一维数组实现，每个元素包含 data 和 next（存放后继元素的数组下标/游标）。

- **链表核心操作复杂度**：查找为 O(n)，已知指针位置插入删除为 O(1)。

# （三）线性表的应用

## 线性表的应用

### 1. 一元多项式的表示与相加

- 利用有序链表或顺序表存储稀疏多项式，按指数递增有序排列，采用双指针归并遍历实现多项式相加。

### 2. 408 核心算法设计题型

- **双指针法（快慢指针、对撞指针）**：寻找链表倒数第 k 个结点、寻找链表中间结点、判断链表是否有环、旋转数组、删除重复元素。

- **逆置与原地重排**：头插法逆置、三步翻转法（数组循环移动 k 位）。

- **时间与空间折中优化**：空间换时间（哈希计数数组）求解未出现的最小正整数等。
