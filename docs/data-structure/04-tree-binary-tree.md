# （一）树的基本概念

## 树的基本概念

### 1. 树的定义与术语

- 结点的度、树的度（最大度数）、叶子结点/分支结点、树的深度/高度、路径长度。

### 2. 树的核心性质

- 结点总数 = 所有结点的度数之和 + 1。

- 度为 m 的树第 i 层至多有 m^(i-1) 个结点。

- 高度为 h 的 m 叉树至多有 (m^h - 1)/(m - 1) 个结点。


---

# （二）二叉树

## 二叉树

### 1. 二叉树的定义及其主要特性

- 满二叉树与完全二叉树的定义与编号性质（结点 i 的双亲为 i/2，左孩子为 2i，右孩子为 2i+1）。

- 非空二叉树叶子结点数 n0 = n2 + 1（度为0的结点数 = 度为2的结点数 + 1）。

### 2. 二叉树的顺序存储结构和链式存储结构

- 顺序存储（适合完全二叉树）与二叉链表（lchild, data, rchild）、三叉链表（加 parent 指针）。

### 3. 二叉树的遍历

- 先序、中序、后序遍历的递归与非递归（栈辅助）实现；层次遍历（队列辅助）。

- 由先序+中序或后序+中序序列唯一确定一棵二叉树。

### 4. 线索二叉树的基本概念和构造

- 利用空指针域存储前驱和后继线索（ltag=1 指向前驱，rtag=1 指向后继）。

- 中序线索二叉树的构造与查找前驱/后继。

# （三）树、森林

## 树、森林

### 1. 树的存储结构

- 双亲表示法（数组+parent下标）、孩子表示法（邻接表）、孩子兄弟表示法（左孩子右兄弟）。

### 2. 森林与二叉树的转换

- 树/森林与二叉树的转换规则（左孩子右兄弟）。

### 3. 树和森林的遍历

- 树的先根遍历 对应 其对应二叉树的先序遍历；

- 树的后根遍历 对应 其对应二叉树的中序遍历。

# （四）树和二叉树的应用

## 树和二叉树的应用

### 1. 哈夫曼（Huffman）树和哈夫曼编码

- 带权路径长度 WPL = sum(w_i * l_i) 最小的二叉树。哈夫曼树中没有度为 1 的结点（只有 n0 和 n2）。

- 哈夫曼编码为前缀编码（无任何编码是另一编码的前缀）。

### 2. 并查集及其应用

- 树的双亲表示法实现。Find(x) 查找根、Union(x, y) 合并。按秩合并与路径压缩使均摊时间复杂度接近 O(1)。

### 3. 堆及其应用

- 大根堆（父 >= 孩子）与小根堆（父 <= 孩子）。建堆时间复杂度 O(n)，插入与删除时间复杂度 O(log n)。
