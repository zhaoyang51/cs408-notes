# 第4章 树和二叉树

## 1. 二叉树核心性质速查

| 性质 | 结论公式 |
|:---|:---|
| **叶子与度为2结点** | $n_0 = n_2 + 1$（任何二叉树必成立） |
| **第 $i$ 层最大结点数** | $2^{i-1}$ |
| **高度为 $h$ 的最大结点数** | $2^h - 1$ |
| **完全二叉树高度** | $h = \lfloor \log_2 n \rfloor + 1$ 或 $\lceil \log_2(n+1) \rceil$ |
| **完全二叉树结点 $i$ 的父子关系** | 左孩子 $2i$，右孩子 $2i+1$，父结点 $\lfloor i/2 \rfloor$ |

---

## 2. 线索二叉树与遍历

- 若 $n$ 个结点的二叉链表，共有 $2n$ 个指针域，其中 $n+1$ 个为空指针域（用于线索化）。
- **线索规则**：左指针为空指向**前驱**，右指针为空指向**后继**。

---

## 3. 哈夫曼树（最优二叉树）与并查集

- **哈夫曼树特点**：只有度为 0 和度为 2 的结点，不存在度为 1 的结点；$n$ 个叶子结点的哈夫曼树总结点数 $= 2n - 1$。
- **带权路径长度 (WPL)**：
  $$WPL = \sum (w_i \times l_i)$$
- **并查集（Union-Find）**：基于双亲表示法树结构，用于高效处理图连通性与 Kruskal 算法（Find 路径压缩 + Union 小树并大树）。
