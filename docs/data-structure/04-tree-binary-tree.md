## 1. 二叉树 5 大核心性质

::: info 💡 二叉树核心性质与公式速查

- **叶子与双分支结点关系**：$n_0 = n_2 + 1$（对任意二叉树恒成立）。
- **第 $i$ 层最大结点数**：$2^{i-1}$。
- **高度为 $h$ 的最大总结点数**：$2^h - 1$。
- **完全二叉树高度**：$h = \lfloor \log_2 n \rfloor + 1 = \lceil \log_2(n+1) \rceil$。
- **完全二叉树编号关系**：结点 $i$ 的左孩子为 $2i$，右孩子为 $2i+1$，父结点为 $\lfloor i/2 \rfloor$。

:::

## 3. 线索二叉树性质

- $n$ 个结点的二叉链表共有 $2n$ 个指针域，其中 **$n+1$ 个为空指针域**（用于构建线索）。
- **线索规则**：
  - `ltag == 1`：`lchild` 指向**前驱结点**；
  - `rtag == 1`：`rchild` 指向**后继结点**。

## 4. 哈夫曼树（最优二叉树）与并查集

| 概念 | 核心性质 | 计算公式 / 算法步骤 |
|:---|:---|:---|
| **哈夫曼树** | 只有度为 0 和度为 2 的结点（无度为 1 结点） | $n$ 个叶子总结点数 $= 2n - 1$ |
| **带权路径长度 (WPL)** | 叶子结点权值 $\times$ 到根路径长度 | $WPL = \sum (w_i \times l_i)$ |
| **并查集 (Union-Find)** | 双亲表示法树结构 | Find 路径压缩 + Union 小树并入大树（近似 $O(1)$） |

::: details 🎯 ⭐️ 考点自测 权值为 $\{2, 3, 5, 7, 8\}$ 的叶子结点构造哈夫曼树，其 WPL 是多少？

- 选 7, 8 合并生成 15（分支和 15）
- 选 10, 15 合并生成 25（分支和 25）

**【WPL 极速算法】**：所有非叶结点的权值之和 $= 5 + 10 + 15 + 25 = 55$。
