# 第1章 基本概念与时空复杂度

## 1. 数据结构三要素

- **逻辑结构**（独立于机器）：
  - 线性结构：线性表、栈、队列、数组、字符串
  - 非线性结构：集合、树（一对多）、图（多对多）
- **物理结构（存储结构）**：顺序存储、链式存储、索引存储、散列存储（Hash）
- **数据运算**：运算定义（基于逻辑结构）+ 运算实现（基于物理结构）

---

## 2. 算法 5 大特性

| 特性 | 含义 |
|:---|:---|
| **有穷性** | 算法必须在有限步和有限时间内结束 |
| **确定性** | 每条指令含义明确，无二义性；相同输入必产生相同输出 |
| **可行性** | 算法中操作都可以通过基本运算有限次实现 |
| **输入** | $\ge 0$ 个输入 |
| **输出** | $\ge 1$ 个输出 |

---

## 3. 渐近时间复杂度与空间复杂度

### 阶数大小排序（必背）
$$O(1) < O(\log_2 n) < O(n) < O(n \log_2 n) < O(n^2) < O(n^3) < O(2^n) < O(n!) < O(n^n)$$

::: tip 💡 408 避坑常考
- **循环次数计算**：如 `for(int i=1; i<n; i*=2)` 时间复杂度为 $O(\log_2 n)$。
- **空间复杂度原地工作**：算法辅助空间为 $O(1)$。
:::
