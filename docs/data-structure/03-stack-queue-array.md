# （一）栈和队列的基本概念

## 栈和队列的基本概念

### 1. 栈（Stack）

- **定义**：只允许在一端进行插入或删除操作的受限线性表。

- **操作特性**：后进先出（LIFO - Last In First Out）。

- **卡特兰数（Catalan）**：n 个不同元素进栈，出栈元素排列的个数为 1/(n+1) * C(2n, n)。

### 2. 队列（Queue）

- **定义**：只允许在表的一端进行插入（入队），而在另一端进行删除（出队）的受限线性表。

- **操作特性**：先进先出（FIFO - First In First Out）。

# （二）栈和队列的顺序存储结构

## 栈和队列的顺序存储结构

### 1. 顺序栈与共享栈

- **顺序栈**：一维数组 + 栈顶指针 top。top=-1 为空，top=MaxSize-1 为满。

- **共享栈**：两个栈共享一块存储空间，栈底分别在数组两端（0 和 MaxSize-1），栈顶相向增长，判满条件为 top0 + 1 == top1。

### 2. 循环队列（解决假溢出）

- **结构**：一维数组 + 队头指针 front + 队尾指针 rear。

- **入队**：Q.data[Q.rear] = x; Q.rear = (Q.rear + 1) % MaxSize;

- **出队**：x = Q.data[Q.front]; Q.front = (Q.front + 1) % MaxSize;

- **区分队空与队满的三种方法**：

- ① 牺牲一个存储单元：队空 Q.front == Q.rear；队满 (Q.rear + 1) % MaxSize == Q.front；队列中元素个数 (Q.rear - Q.front + MaxSize) % MaxSize。

- ② 增加 size 计数变量：队空 size == 0；队满 size == MaxSize。

- ③ 增加 tag 标志位：0 表示最近出队，1 表示最近入队。tag=0 且 front==rear 为空；tag=1 且 front==rear 为满。

# （三）栈和队列的链式存储结构

## 栈和队列的链式存储结构

### 1. 链栈

- 通常采用无头结点的单链表实现，便于在表头（栈顶）进行 O(1) 的入栈和出栈操作，不存在栈满上溢的问题。

### 2. 链队列

- 同时包含头指针 front（指向头结点）和尾指针 rear（指向终端结点）。

- 出队时若最后一个元素出队，需将 rear 指向 front 头结点。

# （四）多维数组的存储

## 多维数组的存储

### 1. 二维数组的存储映射

- **行优先存储（Row-major order）**：LOC(A[i][j]) = LOC(A[0][0]) + (i * n + j) * L。

- **列优先存储（Column-major order）**：LOC(A[i][j]) = LOC(A[0][0]) + (j * m + i) * L。

# （五）特殊矩阵的压缩存储

## 特殊矩阵的压缩存储

### 1. 对称矩阵与三角矩阵

- **对称矩阵**：a[i][j] = a[j][i]。只需存储下三角共 n(n+1)/2 个元素。下标映射（从 1 开始）：i >= j 时 k = i(i-1)/2 + j - 1。

- **三角矩阵**：上三角或下三角除对角线外全为常数 c。压缩方法为存三角区并在末尾存常数 c。

### 2. 三对角矩阵（带状矩阵）

- 3n-2 个非零元素集中在主对角线及其上下两侧对角线。下标映射：k = 2i + j - 3。

### 3. 稀疏矩阵

- **三元组表**：存储 (行号 i, 列号 j, 元素值 val)。

- **十字链表**：每个非零结点包含 row, col, val, right（行链表）, down（列链表）。

# （六）栈、队列和数组的应用

## 栈、队列和数组的应用

### 1. 栈的应用

- **括号匹配检验**：遇到左括号入栈，遇到右括号出栈检验。

- **表达式求值**：中缀转后缀（逆波兰式 RPN）及后缀表达式求值。

- **递归与函数调用**：调用栈保存局部变量、参数及返回地址。

### 2. 队列的应用

- **树和图的层次遍历/广度优先搜索（BFS）**。

- **计算机系统资源管理**：打印机就绪队列、CPU 进程就绪队列、网络缓冲区 FIFO 调度。
