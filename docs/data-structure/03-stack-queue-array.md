# 第3章 栈、队列和数组

## 1. 栈（LIFO）与队列（FIFO）

- **卡特兰数（Catalan）**：$n$ 个不同元素进栈，合法出栈序列总数为：
  $$\frac{1}{n+1} \binom{2n}{n}$$
- **循环队列判空判满（模运算）**：
  - 牺牲一个单元法：
    - 队列为空：`front == rear`
    - 队列为满：`(rear + 1) % MaxSize == front`
    - 队列长度：`(rear - front + MaxSize) % MaxSize`

---

## 2. 栈的应用：表达式求值

- **中缀转后缀核心规则**：
  1. 遇到操作数：直接输出。
  2. 遇到运算符：若优先级高于栈顶则压栈；否则弹出栈顶并输出，直到高于栈顶，再压栈。
  3. 遇到左括号 `(`：直接压栈；遇到右括号 `)`：依次弹出并输出，直到弹出 `(` 为止。

---

## 3. 特殊矩阵压缩存储地址计算

- **对称矩阵 / 三角矩阵**（按行优先存储，下标从 0 开始）：
  - 第 $i$ 行第 $j$ 列元素 $a_{i,j}$（$i \ge j$）在一维数组中的下标：
    $$k = \frac{i(i+1)}{2} + j$$
