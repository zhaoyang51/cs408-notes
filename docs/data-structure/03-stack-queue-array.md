## 1. 栈（LIFO）与合法出栈序列

<div class="formula-card">
  <div class="title">💡 卡特兰数（Catalan Number）公式</div>
  $$n \text{ 个不同元素依次进栈，所有合法的出栈序列总数为：} \frac{1}{n+1} \binom{2n}{n} = \frac{(2n)!}{(n+1)! \, n!}$$
</div>

::: tip ⚠️ 非法出栈序列判定法则
对于出栈序列中的任意元素 $x$，在 $x$ 之后出栈且在原序列中排在 $x$ 之前的元素，必须保持**从大到小（降序）**排列。
:::

## 2. 循环队列状态判断（必考计算）

循环队列采用数组 `Q[MaxSize]`，`front` 指向队头，`rear` 指向队尾下一个位置：

| 方案 | 队空条件 | 队满条件 | 队列中元素个数 |
|:---|:---|:---|:---|
| **牺牲一个单元法** | `front == rear` | `(rear + 1) % MaxSize == front` | `(rear - front + MaxSize) % MaxSize` |
| **增加 size 计数器** | `size == 0` | `size == MaxSize` | `size` |
| **增加 tag 标记** | `front == rear && tag == 0` | `front == rear && tag == 1` | 需根据 tag 推算 |

## 3. 栈的应用：中缀表达式转后缀与求值

| 步骤 | 遇到操作数 | 遇到左括号 `(` | 遇到右括号 `)` | 遇到运算符 (+, -, \*, /) |
|:---|:---|:---|:---|:---|
| **转换规则** | 直接输出 | 立即压栈 | 依次弹出栈顶并输出，直到遇到 `(` 弹出并废弃 | 若优先级高于栈顶则压栈；否则弹出栈顶并输出，直到高于栈顶再压入 |
