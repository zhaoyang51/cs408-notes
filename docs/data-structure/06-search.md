# 六、查找

> 本章包含考点小节：9 个

# （一）查找的基本概念

## 查找的基本概念

### 1. 查找表与关键字

- 静态查找表（仅查询）与动态查找表（支持动态插入和删除）。

### 2. 平均查找长度（ASL）

- ASL = sum(P_i * C_i)，分为查找成功的 ASL_succ 与查找失败的 ASL_fail。


---

# （二）顺序查找法

## 顺序查找法

- 引入“哨兵”可免去越界判断。ASL_succ = (n+1)/2，ASL_fail = n+1，时间复杂度 O(n)。


---

# （三）分块查找法

## 分块查找法

- 索引顺序表结构（块间有序、块内无序）。第一步在索引表中查找分块，第二步在块内顺序查找。

- 当每块长度为 sqrt(n) 时，ASL 取得极小值 sqrt(n) + 1。


---

# （四）折半查找法

## 折半查找法

- 仅适用于顺序存储的有序表。判定树高度为 ceil(log2(n+1))，时间复杂度 O(log2 n)。


---

# （五）树型查找

## 树型查找

### 1. 二叉搜索树（BST）

- 左子树所有结点 < 根 < 右子树所有结点。中序遍历单调递增。查增删平均 O(log n)，最坏单支树 O(n)。

### 2. 平衡二叉树（AVL）

- 任意结点的平衡因子绝对值 <= 1。四种失衡旋转调整：LL、RR、LR、RL 旋转。查找时间复杂度严格为 O(log n)。

### 3. 红黑树（RBT）

- 五大性质：结点非黑即红；根结点是黑色；叶子结点(NIL)是黑色；不存在相邻红结点；任意结点到其所有叶结点的黑高相同。

- 查找、插入、删除效率稳定在 O(log n)。


---

# （六）B树及其基本操作、B+树的基本概念

## B树及其基本操作、B+树的基本概念

### 1. B树（多路平衡查找树）

- m 阶 B 树：根结点至少 2 棵子树；非根非叶结点子树数 ceil(m/2) ~ m，关键字数 ceil(m/2)-1 ~ m-1；所有叶子结点都在同一层。

- 插入：超限分裂；删除：借兄弟借父亲或与兄弟合并。

### 2. B+树

- 非叶结点的关键字数 = 子树数；所有数据记录集中在叶子结点层并由链表相连（支持顺序范围查找）。常用于数据库索引。


---

# （七）散列（Hash）表

## 散列（Hash）表

### 1. 散列函数构造

- 直接定址法、除留余数法 H(key) = key % p。

### 2. 冲突处理

- 开放定址法（线性探测、二次探测、伪随机探测）；拉链法（链地址法）。

### 3. 装填因子与 ASL

- 装填因子 alpha = 记录数 / 表长。ASL 取决于散列函数、处理冲突方法和装填因子。


---

# （八）字符串模式匹配

## 字符串模式匹配

### 1. BF 朴素模式匹配

- 暴力回溯匹配，最坏时间复杂度 O(m * n)。

### 2. KMP 算法

- 利用主串指针不回溯，利用 next/nextval 数组加速，时间复杂度 O(m + n)。
