## 1. 树型查找结构特性对比

| 数据结构 | 平衡定义 | 查找/插入/删除时间复杂度 | 核心应用场景 |
|:---|:---|:---:|:---|
| **二叉排序树 (BST)** | 左子树 $<$ 根 $<$ 右子树 | 最坏 $O(n)$，平均 $O(\log n)$ | 基础内存动态检索 |
| **平衡二叉树 (AVL)** | 任意结点左右子树高度差 $\le 1$ | 严格 $O(\log_2 n)$ | 读多写少场景（旋转代价高） |
| **红黑树 (R-B Tree)** | 根黑、叶黑、红子必黑、任意路径黑高相同 | $O(\log_2 n)$ | C++ STL `map`/`set`（写性能好） |
| **B 树 (多路平衡)** | 所有叶子在同层，$m$ 阶非根结点孩子数 $\ge \lceil m/2 \rceil$ | $O(\log_m n)$ | **磁盘与数据库索引** |
| **B+ 树** | 非叶结点仅存索引，所有数据在叶子链表中 | $O(\log_m n)$ | 数据库范围查询（如 MySQL InnoDB） |

## 2. 散列表（Hash Table）与冲突解决

::: info 💡 平均查找长度 (ASL) 与装填因子公式


$$
\text{装填因子 } \alpha = \frac{\text{表中记录数 } n}{\text{散列表长度 } m}
$$


  


$$
\text{散列查找效率取决于：① 散列函数；② 冲突处理策略；③ 装填因子 } \alpha
$$


:::

| 处理冲突方法 | 探测序列公式 | 优缺点分析 |
|:---|:---|:---|
| **线性探测法** | $d_i = 1, 2, 3, \dots, m-1$ | 易产生 **二次聚集（同义词与非同义词堆积）** |
| **平方探测法** | $d_i = \pm 1^2, \pm 2^2, \dots, \pm k^2$ | 有效避免堆积，但不能探查到所有单元 |
| **拉链法 (链地址法)** | 同义词串入单链表 | 空间利用率高，无堆积现象 |
