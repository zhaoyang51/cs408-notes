# 第6章 查找与散列

## 1. 树型查找核心对比

| 结构 | 平衡因子 / 特征 | 查找/插入/删除时间复杂度 |
|:---|:---|:---:|
| **二叉排序树 (BST)** | 左子树 $<$ 根 $<$ 右子树（中序遍历递增） | 最坏 $O(n)$，最好 $O(\log n)$ |
| **平衡二叉树 (AVL)** | 任意结点左右子树高度差 $\le 1$ | 严格 $O(\log_2 n)$ |
| **红黑树 (R-B Tree)** | 根黑、叶黑、红结点的子必黑、任意结点到叶黑高相同 | $O(\log_2 n)$（插入旋转比 AVL 少） |
| **B 树 / B+ 树** | 多路平衡查找树，常用于磁盘与数据库索引 | $O(\log_m n)$ |

## 2. 散列表（Hash Table）

- **解决冲突方法**：
  - 开放定址法：线性探测法（易产生二次聚集）、平方探测法、双散列法。
  - 拉链法（链地址法）。
- **平均查找长度 (ASL)**：查找成功 ASL 与查找失败 ASL 计算。散列查找效率取决于**散列函数**、**处理冲突方法**与**装填因子** $\alpha = \frac{n}{m}$。
