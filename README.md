## ✍️ 408 真题分类做题本与刷题中心

依据《408 真题分类∙做题本》整理，全面收录 **2009—2026 年统考真题共 846 题**（含单项选择题与综合应用题）。

### 核心刷题功能特性：
1. **多维精准筛选**：按 4 大科目、97 个细分章节考点、单选/大题、年份（2009~2026）自由组合过滤；
2. **沉浸式做题交互**：单选题点击即时判分，即时呈现正确/错误反馈，一键展开官方答案与核心考点精析；
3. **综合大题草稿纸**：每道大题内置手写做题草稿纸，思路自动保存至本地；
4. **错题本与收藏夹**：错题自动收录进错题库，支持一键切换“错题攻坚”模式，支持星标收藏经典好题；
5. **双向考点联动**：每道真题均附带知识库章节反查链接，做题时一键直达对应知识点讲义，实现“刷题-查纲-巩固”闭环；
6. **本地缓存持久化**：刷题进度、答题卡、错题与做题笔记均安全保存在浏览器本地，随时随地离线刷题。

## 👥 知识点贡献者标记与分组筛选

站点顶部导航栏内置**用户筛选控制器**，支持在「全部用户」、「Zhao」、「Chen」之间一键切换，并自动记忆筛选偏好。

### 如何标记知识点归属用户：

1. **使用 `<KP>` 知识点卡片容器（推荐）**：
   ```html
   <KP author="Zhao" title="核心口诀：阶数大小比较" tag="💡 必背">
     知识点内容...
   </KP>

   <KP author="Chen" title="主定理秒杀公式" tag="⭐️ 技巧">
     知识点内容...
   </KP>
   ```

2. **使用 `<AuthorTag>` 徽章组件**：
   ```html
   <AuthorTag user="Zhao" />
   <AuthorTag user="Chen" />
   ```

3. **使用 HTML 属性 / CSS 类名**：
   ```html
   <div class="kp-block" data-author="Zhao">...</div>
   <details class="self-test author-chen" data-author="Chen">...</details>
   <span class="badge badge-zhao">Zhao</span>
   <span class="badge badge-chen">Chen</span>
   ```
